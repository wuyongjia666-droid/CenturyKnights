> 版本：0.1-plan · 2026-10-07（Asia/Shanghai）

> 配套：`game-brief.md` · `systems-catalog.md` · `epics.md` · `sprint-status.yaml`  
> 对标：公开资料中的《诸神皇冠：百年骑士团》**玩法系统深度**（非资产/剧情/地图复刻）

---

## 0. 设计原则

1. **系统同型 ≥ 对标公开深度**；在可验证处 **超过**（见 §6）。  
2. **原创 IP**：朔澜陆桥、灰烬旗、第零章剧情与全部 UI 文案原创。  
3. **新手剧情非可选**：第零章是主路径，教战斗+招募+城堡+联姻传代。  
4. **数据先于感觉**：联姻/遗传/年龄必须有可测规则与 UI 可见结果。  
5. **MVP = 20–30 分钟陌生人可感「王朝闭环」**。

## 1. MVP 体验脚本（目标 20–30 分钟）

| 分钟 | 节拍 | 玩家做什么 | 系统触点 |
|------|------|------------|----------|
| 0–3 | 序章旁白 + 命名 | 定团长姓名/姓氏纹章色 | 存档、Localization |
| 3–8 | 第零章·战① 隘口遭遇 | 网格战棋教学：移动/攻击/结束回合 | SRPG 核心 |
| 8–12 | 战后酒馆 | 招募 1 名佣兵（看六维/血脉/特性） | 佣兵团、招募 |
| 12–16 | 入驻灰旗堡 | 城堡枢纽：编队、任务板、家族页 | 城堡 Hub |
| 16–22 | 第零章·联姻节拍 | 声望够门槛 → 相亲 → 成婚 | 声望、爵位、联姻 |
| 22–26 | 产子与遗传面板 | 看见孩子外貌/特性/资质继承条 | 血统遗传 |
| 26–30 | 岁月推进 | 推进数月→丰收式结算→角色年龄+1 可见；可选再战一局 | 时间、老化、任务 |

退出条件：玩家能口头复述「打仗养团 → 进堡 → 结婚生娃会遗传 → 人会变老」。

## 3. MVP 系统规格（可测）

### 3.1 灰旗战棋（SRPG）

- 网格：方形，默认 8×6 教程图；地形：平地/林/丘（移动力差、回避差）。  
- 单位回合：移动 → 行动（攻击/技能/待命）→ 结束。  
- 伤害（MVP）：`max(1, Atk - Def/2) ± 浮动`；命中受技巧与等级差影响。  
- 胜负：歼灭 / 抵达 / 存活 N 回合（第零章战①用歼灭）。  
- 编队上限 MVP：4 人上场。  
- **超过对标（教学）**：战斗内可选「规则透视」显示命中/伤害区间（新手默认开）。

### 3.2 佣兵团与招募

- 资源：银币、粮、士气（0–100）。  
- 酒馆每日刷新 3 候选；展示：六维雷达、血胤、禀性、勋位、月薪。  
- 招募扣银币；入队进「花名册」。  
- 子女：出生记入家族；`age >= adult_age(默认15)` 可「授旗入队」。

### 3.3 灰旗堡（单城堡 Hub）

建筑（MVP）：大厅、酒馆入口、委任榜、演武场、炉火工坊、祠堂、家族祠谱、岁月沙漏。  
操作：编队、接任务、训练（耗时+银）、打造白装、推进时间、打开联姻廷。

### 3.4 联姻 · 血胤 · 遗传（核心愉悦）

**勋位门槛 × 声望（MVP 数值可调）：**

| 对象勋位 | 所需对本邦声望档 |
|----------|------------------|
| 骑士 | 认识 |
| 男爵 | 友善 |
| 伯爵 | 信赖 |
| 公爵 | 尊敬 |

**遗传规则（MVP，必须 UI 可见）：**

1. **六维资质上下限**：子代每维 `lerp(父限, 母限, w) + 突变`；血胤表提供 base min/max。  
2. **禀性**：每个禀性有显性权重；子代 2–4 条；可遗传「营养不良」等负面（粮饷不足时）。  
3. **容貌基因**：发色/瞳色/眉型/疤痕槽等离散等位；**超过**：订婚前「子嗣期望」面板显示概率条。  
4. **血胤比例**：记录父系/母系权重；混合条可视化（超越「只看词条碰运气」）。  
5. **勋位继承**：子代默认继承父母较高勋位的降一档或同档（可配置）；影响再联姻池。

成婚流程：候选列表 → 检声望 → 定聘礼 → 婚宴（加少量声望）→ 标记配偶 → 时间后妊娠检定 → 出生事件。

### 3.5 岁月轴 · 老化 · 死亡

- 时间单位：月；UI 显示「第 Y 年 M 月」。  
- 推进：任务耗时、训练耗时、「沙漏：度过一月/一季」。  
- 年龄每年 +1（生日月）；`age >= retire_age` 强制退役可任顾问；`age >= death_age` 或健康归零 → 死亡 → 族谱碑。  
- 第零章用「岁月压缩」让玩家在 30 分钟内看到：结婚→怀孕→出生→（可选）快进到儿童预览。

### 3.6 第零章 · 灰旗初升（新手剧情 · 必含）

**定位**：可玩战役，不是跳过提示条。原创文案，禁止复述诸神皇冠剧情句。

| 节 | 标题 | 教学点 | 失败友好 |
|----|------|--------|----------|
| 0.0 | 破旗 | 命名、世界观一句 | — |
| 0.1 | 隘口之夜 | 移动/攻击/地形 | 可重开；僚机 AI 保姆 |
| 0.2 | 酒馆赊账 | 招募解读六维与禀性 | 送 1 银充足 |
| 0.3 | 灰旗堡灯火 | Hub 导航 | 高亮指引 |
| 0.4 | 春令试婚 | 声望/勋位/联姻 | 剧本给予友善声望 |
| 0.5 | 初啼 | 遗传面板解读 | 必出 1 子 |
| 0.6 | 秋收簿 | 粮饷/士气/年龄+ | 奖励结算 |

**超过**：章末「王朝手记」一页，总结本代选择对血胤的影响（养成元叙事）。

### 3.7 任务 · 商路 lite · 工坊

- 委任榜：3 个任务（护商/清匪/演习），星级 1–3，耗月、给银币与声望。  
- 商路 lite：堡内市场价格表，买卖 3 种物资（粮/铁/药）。  
- 工坊：打造 3 件基础武器；装备加减攻防。

### 3.8 职阶（MVP 子集）

初职 5：见习骑手、轻步、重步、猎手、学徒秘术。  
二转（开放 4）：轻骑、勇士、弓手、祭司。  
全三转表进完整版；规则「属性达标+物资即可转，不锁前职」与对标同型。

## 4. 经济与节奏（MVP）

- 开局银币足以完成第零章；不设计付费。  
- 月度：工资 = Σ 月薪；粮耗 = f(人数, 儿童)；不足 → 士气↓ + 儿童负面禀性风险。  
- 丰收月（第 8 月）：城堡基础产出 + 祠堂加成。

## 5. UI / 本地化

- 全部玩家可见字符串：**简体中文**。  
- 关键屏幕：主菜单、对话、战斗 HUD、城堡、人物卡、联姻、遗传期望、族谱、岁月结算。  
- 无障碍：战斗伤害预览开关；色弱友好血胤条（不只靠颜色）。
