# 游戏简报 · 百年骑士·同型原创（CenturyKnights）

> 状态：MVP 已实现（编码/试玩包已交付）  
> 日期：2026-10-07（Asia/Shanghai）  
> 引擎意向：Godot 4.x  
> 边界：系统同型致敬；原创 IP（地名/家族/剧情/UI 文案）；禁止反编译 APK/IPA、禁止素材/地图/原文 1:1 复制；不复用 GeneRanch 残留。

---

## 1. 一句话定位

一款以「佣兵团百年王朝」为核心快感的回合制战棋 SRPG：带队征战、经营城堡、联姻传代、岁月催人，在数十年尺度上把「长相 / 特性 / 资质」写成可玩的血脉故事。

## 2. 核心愉悦（玩家点名）

| 愉悦点 | 说明 | 设计承诺 |
|--------|------|----------|
| 联姻 | 择偶看爵位、血脉、声望门槛 | MVP 即有完整相亲→成婚→产子链路 |
| 血统 / 传代 | 后代继承外貌、特性、资质上下限 | 遗传学面板透明，可预览期望值 |
| 人物老去死 | 年龄、伤病、退休、死亡 | 时间轴驱动，王朝必须换代 |
| 王朝跨越数十年 | 月/年推进，节庆节奏 | 新手章内即可感到「岁月」 |
| 佣兵战棋环 | 接任务→编队→战棋→赏金→培养 | 与城堡/联姻闭环咬合 |

## 3. 对标与边界（诸神皇冠：百年骑士团 · 公开资料）

**对标的是玩法系统深度，不是资产或剧情。**

公开玩点（FAQ / 商店页 / 攻略社区）：主线剧情、高自由度佣兵、骑士招募·联姻·培养、装备培养、城堡经营；另有声望、爵位、血脉上下限、六维属性、三阶转职、伤病、节庆（启航/春临/丰收/勇士/亡人）、酒馆招募、子女成年入队、传家宝等。

**我们做：** 同型系统完整度 ≥ 对标公开深度，并在可验证处「超过」（见 GDD「超越条」）。  
**我们不做：** 加尔提兰/六国原文、官方角色与关卡复刻、拆包资源、破解。

## 4. 原创世界观锚点（计划级）

- 大陆：**朔澜陆桥**（原创）  
- 玩家身份：边境佣兵团「灰烬旗」创始团长（可改姓）  
- 王朝主题：在乱世中把一面破旗传成百年纹章  
- 新手章程式名：**第零章 · 灰旗初升**（教程战役，非可跳过弹窗）

## 5. 目标体验时长

| 阶段 | 时长 | 玩家应带走的感觉 |
|------|------|------------------|
| MVP（陌生人试玩） | 20–30 分钟 | 打过仗、进过堡、结过婚、见过孩子继承、推过岁月 |
| 垂直切片后 | 2–4 小时 | 一轮完整「接单→转职→春临联姻→丰收结算」 |
| 完整体愿景 | 数十小时 / 多代 | 真正的百年骑士团感 |

## 6. 平台与技术

- 引擎：Godot 4.x（已在箱内验证 4.3 可用；实现阶段再开工）  
- 语言：GDScript；数据驱动（JSON/Resource）  
- UI：中文为主（简体）  
- 发布：本阶段 **不出包、不 Windows 交付**；仅计划与后续本地 git

## 7. 成功标准（计划验收）

1. 系统对照表每一行有「MVP / 超越 / 后置」归属与 AC。  
2. 第零章新手剧情为 MVP **必含**史诗，不可标成可选。  
3. 联姻→出生性状可见→年龄推进三条链路在 GDD 中有数据规则，而非口号。  
4. Epics 带可测 AC，可直接开 sprint。

## 8. 风险与不做清单

| 风险 | 缓解 |
|------|------|
| 误做成「浅联姻」 | 遗传学与爵位/声望门槛写入 MVP AC |
| 剧情像说明书 | 第零章用角色冲突推进教学，不纯弹提示 |
| 范围膨胀 | 完整体愿景入 GDD「后置」，MVP 锁死清单 |
| 版权擦边 | 全原创专名；对照表只写系统名不写抄关 |

**明确不做（本阶段）：** 编码实现、反编译、素材搬运、GitHub 强推（除非后续用户再批）、Windows 安装包。
