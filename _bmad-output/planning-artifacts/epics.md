## Epic E0 — 工程骨架与中文壳

**目标：** Godot 4 工程可启动；中文主菜单；Autoload 空壳；数据目录约定。  
**范围：** `project.godot`、主场景、Locale、占位场景路由。  
**不做：** 玩法逻辑。

### AC
- [ ] AC-E0.1 用 Godot 4.x 打开工程无报错；主菜单四字可见：「新的旗号 / 继续历程 / 设置 / 退出」。
- [ ] AC-E0.2 Autoload 注册：`GameState` `Calendar` `Locale` `Lineage` `BattleRules`（可先空实现）。
- [ ] AC-E0.3 `data/` 含血胤、禀性、职阶、第零章脚本的 JSON schema 样例（各 ≥1 条真实数据）。
- [ ] AC-E0.4 README 写明运行方式；本阶段不强制 Windows 包。

## Epic E1 — 第零章·灰旗初升（新手剧情 · 必含）

**目标：** 可玩章节驱动教学，覆盖战→招→堡→婚→子→岁月。  
**范围：** 章节状态机、对话 UI、节拍锁系统解锁、原创文案。  
**系统目录：** A01–A04, I09。

### AC
- [ ] AC-E1.1 新游戏强制进入第零章；不可在未完成 0.1 前进入自由沙盒。
- [ ] AC-E1.2 节拍 0.0–0.6 均有中文标题与对白；无诸神皇冠剧情原文句。
- [ ] AC-E1.3 每节结束写入 `chapter0.flags`；城堡/联姻等入口按旗标解锁。
- [ ] AC-E1.4 节拍失败（战败）可重试，不毁存档进度旗标。
- [ ] AC-E1.5 章末生成「王朝手记」一页（X4），含团长名、配偶、子嗣血胤摘要。
- [ ] AC-E1.6 全程目标时长设计 ≤30 分钟（文案与战斗规模受控）。

## Epic E2 — 灰旗战棋 MVP

**目标：** 可部署的网格 SRPG 一局完整胜负。  
**范围：** 地图、单位、回合、伤害、AI、伤害透视。  
**系统目录：** B01–B12, B16–B17, B08。

### AC
- [ ] AC-E2.1 8×6（或配置）地图；至少 3 种地形并影响移动或回避。
- [ ] AC-E2.2 玩家单位可移动、攻击、待命；非法格不可站。
- [ ] AC-E2.3 命中与伤害使用六维派生；UI 可开关「规则透视」显示区间（X3）。
- [ ] AC-E2.4 敌方 AI 每回合至少执行移动或攻击之一。
- [ ] AC-E2.5 歼灭胜利/全灭失败；战后回写 HP 与临时伤标记。
- [ ] AC-E2.6 第零章战①调用本系统；部署位 ≤4。

## Epic E3 — 佣兵团 · 酒馆 · 委任榜

**目标：** 花名册+招募+接任务经济闭环。  
**范围：** E01–E07, C01–C03。  
**依赖：** E0；与 E2 战后结算对接。

### AC
- [ ] AC-E3.1 花名册列出姓名、职、六维摘要、月薪、伤病状态。
- [ ] AC-E3.2 酒馆刷新 3 人；可花银币招募；不足时中文提示。
- [ ] AC-E3.3 委任榜 ≥3 任务；接取后耗月、给银币与声望；可进战斗或自动演习（至少 1 个真实战斗任务）。
- [ ] AC-E3.4 战后/任务结算经验与掉银写入 GameState。
- [ ] AC-E3.5 第零章 0.2 必须完成 1 次招募才继续。

**范围：** F01,F03,F04, G01,G05,G06,G08,G09, E04–E06, C12。

## Epic E5 — 联姻 · 血胤 · 遗传 · 族谱

**目标：** 核心愉悦完整可玩且透明。  
**范围：** D01–D16, D18, H01–H02, X1,X2。  
**依赖：** E3/E4 声望与人物；E1 节拍 0.4–0.5。

### AC
- [ ] AC-E5.1 血胤表 ≥4 条（含平民与贵胤）；影响六维上下限。
- [ ] AC-E5.2 联姻候选受勋位加权；声望不足不可表白并提示差几档。
- [ ] AC-E5.3 订婚前「子嗣期望」面板显示容貌/禀性/六维区间概率（X1）。
- [ ] AC-E5.4 成婚→妊娠→出生；新生儿写入族谱；人物卡显示血胤混合条（X2）。
- [ ] AC-E5.5 禀性 2–4 条按权重继承；粮饷惩罚可注入负面禀性。
- [ ] AC-E5.6 儿童可预览；`age>=15`（或教程加速后的等价）可授旗入队。
- [ ] AC-E5.7 第零章 0.4–0.5 跑通且必出 1 子。
