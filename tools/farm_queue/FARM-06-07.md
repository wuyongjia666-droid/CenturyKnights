1. **入口**：`tools/farm_v87/gen_hunyuan_v87.py` + `farm.ps1`（SaveGLB）；勿并进 `dual_submit_stills`。
2. **清单目标**（backlog FARM-06）：每国 ≥2 敌军轮廓；约 11 个新职业装甲；1 套坐骑；统一骨架 + 8 个基础动作名；toon 参数遵守 `docs/art/style-lock-v89.json`。
3. **验收**：`enemy_theme_check` 通过；每 GLB 三角面 ≤ 15k。
4. **依赖**：BTL-06、CUT-02；产出交接 `project/data/enemy_themes.json` 与 CUT-06。
5. **落点**：`project/assets/models/units/*.glb`、`project/assets/models/mounts/*.glb`。
6. **执行顺序建议**：先 1 国敌军 + 1 坐骑冒烟 → 扩十国轮廓 → 新职业装甲 → 骑乘绑定给 CUT/unit_model。
