## 1. 一句

石垒坡的平民有本事，也有野心：靠自己挣一个称呼，立一个家。第一个肯跟的是同乡旧识石垒·晚担。断旗那夜，布认下已经写下的姓和色。隘口的烽火把这个姓送进传闻。酒馆收进陌生人。灰旗堡的名册上还是空席。春令是政治试婚，情爱推到这一季之后。初啼落地，粮饷结清，然后才上路，走进陆桥。

## 2. 连续读本

麦还没黄。田埂上的石担放下来，陆桥那边已经有烟。你没有爵，没有一扇肯为你开的门。你吃得下更长的路。你要的是一个别人不得不念的姓，和一座能把这个姓留下的家。

石垒·晚担还站在田埂上。他去年就听过这句话。旗可以以后再有。人他现在就跟。他跟的是田埂上这个人。旗若散了，他还认得。

隘口外，旗杆断着。灰布被烟熏黑，仍钉在半截杆上。姓和颜色在来之前已经写下。老旗手让布认字。从这一夜起，石垒坡出来的人要被叫做团长。苇原·灯影也在。她留下，是因为隘口那条路还得有人走。她把那句已经写进圣经的话原样说完：没姓的旗，风一吹就散。一个跟的是人，一个跟的是路。布都收下。

北隘的烽亮了。那不是炊烟。窄路被卡着，堡里的粮撑不了几顿。这一仗打赢，陆桥才肯停下来问姓什么。你选落点，灯影守侧翼。晚担看着身后的人还在不在。烟散之后，活口说出背后有人收过路银。名字他不肯吐。你的手在抖。姓还在。

烽火酒馆的门轴一响，响的是想把这个月卖出去的嘴。至少带走一个陌生人。他跟的是月饷，不是田埂。

破堡亮起第一盏灯。花名册上写得下的人很少，空席很多。空椅子不会因为你想立家就自己坐上人。

春令的帖来了。诸邦看旗，也看家。这场婚是试：人先入席，情爱不在这一季结算。入席前把期望那一行自己念完。念不下去，就不要点头。亲属把人托给旗，托的是以后孩子敢不敢承认这块布。晚担听见你没有把喜欢说出口。他觉得这席因此是实的。

哭声先来。肺是孩子自己的。旗排在这声哭后面。族谱上新的一行，是以后的城门用来认这个孩子的东西。然后才是丰收月。工资、口粮、士气要结清，孩子也吃。账清了，晚担跟的那个人还在。手记写下这一年。陆桥会重复这个姓。你得在场。

## 3. 情感赌注

这一章的身体顺序是：野心，跟随，被看见，手抖，空椅子，一场不谈爱的婚，一声哭，一本结清的簿，然后上路。

| 谁 | 这一夜若失败，失去的是什么 |
|---|---|
| 团长 | 回到石垒坡，仍是一双能扛石担的手。陆桥不必停下来念这个姓。家没有开始。 |
| 石垒·晚担 | 他把出门押在一个人身上。旗若把这个人吃掉，他的忠诚没有地方放。 |
| 苇原·灯影 | 路若断在隘口，后面的城埠都不必谈。姓对她仍是可以涂改的东西。她留，是因为路。 |
| 老旗手 | 这块布若没人扛，就只是坟前的布。他要的是完整，是有人把已经写下的字认下去。 |
| 酒馆里的陌生人 | 被看走眼，这个月的命就贱卖了。月饷是他们留下的理由。 |
| 空席 | 家里若只有认得的人，那仍是一伙人。另一国不会把人托给一伙人。 |
| 试婚的对方 | 把一个人放进一面只打过一夜的旗。当夜的喜欢会变成对方可以追责的谎。推迟爱情，是保护席上的人。 |
| 初啼 | 孩子没有报名参加这场试婚。城门以后读的是这一页，不是父母的野心。 |
| 粮饷簿 | 结不清，晚担跟的就是一个故事。上路之前，故事要先变成发得出的银和粮。 |

第零章挣到的称呼是「团长」，加上灰烬邦的门开到能递帖。爵不在这一章颁发。使者可以点明：还没有爵。下一道门因此还在，野心不会在春令夜里被提前兑完。

## 6. 逐拍

### 6.1 微末立志（`0.0` 前段）

石垒坡，麦还没黄。团长把石担搁下，看陆桥的烟。没有爵，没有肯开的门。野心说清楚：挣一个称呼，立一个家。

此地用舆图已有的 `stone_slope` / 石垒坡。条目里「直到灰旗来了」是旗立住以后的传闻。开场不引用这句，只写佃庄、麦、石担和采石坡上的风。

### 6.2 同乡跟旗（`0.0` 中段）

旁白先把田埂和野心放下。晚担接着开口，早于灯影。他去年就听过这个野心。他现在跟的是人。旗可以以后再有。

### 6.3 断旗夜接姓色（`0.0` 后段与 `0.05`）

旗杆断在隘口外。老旗手不重新讨一个姓。命名画面已经问过。他承认布认下那些字，然后把团长这个称呼放到石垒坡出来的人身上。

晚担补一句：他认得田埂上的人。灯影随后说出路，并说完那句原话。老旗手收下两种跟随。

`0.05` 看颜色落进旗心。老旗手的手在抖，因为他太久没见过一整块还肯认人的布。斥候带来烽。灯影下令，不下教学。晚担说烽火要的是一个名字。

### 6.4 隘口烽火立名（`0.1`、`0.15`）

烽已经亮了。行动仍进 `ch0_pass`，目标仍是击溃。对白里不出现「教学」「四对二」。战败重试、不毁进度的那条禁用提示可以改成一句人话，门仍是禁用按钮。

烟散之后：灯影的箭钉在爬行者面前的石头上。活口说背后有人收过路银。不给名字。晚担看见团长的手在抖，把抖留在掌心，把隘口留给传闻。人数不够，所以去酒馆。

### 6.5 酒馆聚人（`0.2`、`0.25`）

掌柜谈月饷和脸，要求至少带走一个。晚担声明自己已经在队里，柜上这个人是陌生人。`recruited` 只表示这个陌生人。看走眼的代价是月饷，不是一张属性表。

新人先看旗。灯影让他们先看见堡里的灯。晚担指出：只有认得的名字，就还是一伙人。

### 6.6 灰旗堡名册空席（`0.3`）

第一盏灯照见旧刀痕。管事翻开花名册，让人看见空席。今晚的句子停在名册、伤和士气。

枢纽场景今天仍会露出别的门。锁门是 NAR-05 / UX-06 的事，不在本弧。台词只说「今晚先看这本名册」，不说那些门打不开。玩家一点进去就能看见别的门，叙述不能撒谎。

### 6.7 春令政治试婚（`0.35`、`0.4`、`0.45`）

锣声里的闲话把四件事叠在一起：隘口打赢了，旗是新的，人还没成亲，也还没有爵。使者的信把帖定义成试家，不定义成情书。

`0.4` 的 `prepare` 仍在声望不足时把灰烬邦补到友善。使者的人话是：「灰烬这边的门，我代你问过了。」对白里不出现「剧本保证」。

试婚三句：人先入席；情爱不在这一季结算；期望那一行要自己念完，念不下去就不要点头。孩子不来今夜。

「期望那一行」是为了让以后霜阙·晚霜那句听过的话有前史。这里点到为止，不讲解血怎么混合。

双姓共席上，亲属把人托给旗。晚担听见喜欢没有被说出口，认为席因此是实的。灯影仍说家有了、初啼未到、那一页还空着。

不新增「拒绝爱情」旗标。配偶是谁，仍由联姻廷决定。`married` 仍是赴席的唯一门。

### 6.8 初啼与结清粮饷（`0.5`、`0.55`、`0.6` 前段）

稳婆先说哭声和肺。旗在后面。那一页给以后的城门认孩子，不给团长的野心认。晚担说石垒坡没有给这种哭声留座位，家从这一声开始算人数。

然后才是簿。粮饷簿不认眼泪，也不认初啼。工资、口粮、士气结清，孩子也吃。账若结不清，哭声就还是故事。晚担在饷清之后确认：他跟的那个人还在。

月份仍用原来的 `advance`、`fast_harvest` 和岁月场景。按钮文案改成人为什么要去，场景路径不动。

### 6.9 上路陆桥（`0.6` 后段）

手记写下这一年：平民把自己做成了一个姓。有战，有跟着的人，有试过的婚，有孩子，有一本结清的簿。陆桥会重复这个姓，人得在场。

「踏上第一章·陆桥烽火」六个字的按钮全文不动。按下后仍是旧卷封存说明，不切到已删除的章节场景。自由返回堡的那条路也留，只是把「自由游玩」从按钮上拿掉。
