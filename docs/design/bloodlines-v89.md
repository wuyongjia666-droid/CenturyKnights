# 百年骑士 · 十国血胤 v8.9（Nation Bloodlines）

> **血是所携，冕是所显。** 血统百分比（`blood_mix`）只是家谱上的声称，基因（`genome.sig`）才决定一个人携带什么；而王族专属战技、继承资格、酒馆标价，都只看他**脸上显出来的冕征**。
>
> 数据：`project/data/bloodlines_v89.json`（31 条血胤、10 国冕征血律，另加年觉与纯血、每国王胤一套 6–8 个征）· 代码：`project/scripts/characters/bloodline_v89.gd`（`CKBloodline`）· 肖像锁：`docs/art/style-lock-v89.json` · 测试：`tools/check_bloodlines_v89.py`、`project/tests/bloodline_v89_check.tscn`。
>
> 美术基调：2026 当代奇幻，磨砂玻璃、晶霜、薄荷（友）、珊瑚（敌）；拒绝中世纪羊皮纸。

## 0. 设计支柱

1. **十国十律。** 每个国家的王族冕征按一种不同的遗传律传承：显性、隐性、剂量、阈值、Y 连锁、X 显性、母系、外显率、互补、觉醒。**继承法直接从遗传律推出来**，所以每国的政治是不同的。
2. **一眼可读，近看见真。** 每国有一条视觉语言阶梯：民胤 2–3 个地域征，贵胤 3–5 个（王室弱回声加自家一征），王胤是完整的 6–8 征签名集。显隐分三档（明征 / 隐征 / 潜征），酒馆里能不能看出来取决于你的人。伪胤描得了明征，描不出要近看的隐征。
3. **携与显分离。** 一个只有 12% 王血但显冕的人能承座、能用王技；一个 60% 王血却只携不显的人，在多数国家是「边血」。
4. **原创外观。** 参考《诸神皇冠》只取系统深度（可读的血统、王族专属、继承戏剧）。外观一律原创，见 §1。
5. **一张完整肖像（Plan A）。** 每个单位一张 Qwen 全幅肖像，提示词由基因组 + 冕征子句生成；父母特征写进子嗣子句，不做纸娃娃分层。

## 1. 原创边界（反套路锁）

| 禁止 | 落实位置 |
|---|---|

## 2. 体系总览

### 2.1 三层血胤

| 层 | 名 | 酒馆稀有度 | 月俸加成 | 说明 |
|---|---|---|---|---|
| royal | 王胤 | 传说 / 罕见 | +6 | 每国 1 条；默认不进酒馆，需邦交门槛或流亡 |
| noble | 贵胤 | 少见 | +2 | 每国 1 条（星津 2 条：东虹 / 西虹） |
| folk | 民胤 | 常见 | 0 | 每国 1 条地域民胤；陆桥混合四国民胤 |

### 2.2 三档显隐

| 档 | 名 | 谁看得见 | 酒馆定价 |
|---|---|---|---|
| overt | 明征 | 所有人（王胤冕征都是明征） | 老板会算进价钱 |
| subtle | 隐征 | 队中有感知 ≥14 者，或祠堂 ≥2 级（`CKBloodline.inspect_level()`） | 老板常看漏：捡漏机会 |
| latent | 潜征 | 只有祠堂验血 | 无征之冕半价 |

### 2.3 冕征 ≠ 血统 ≠ 冠饰

- **冕征**：基因决定、肖像可见、决定王技与继承。
- **血统**：`blood_mix`，决定六维资质区间、地域服饰、联姻外交；可以伪造（伪胤）。
- **冠饰（regalia）**：有座、有爵（男爵及以上）的王/贵胤才佩戴；纸冕者有冠饰无冕征，流裔有冕征无冠饰。两者都直接写进 Plan A 肖像子句，**玩家从画上就能读出这个人是真是假、在不在位**。

## 3. 遗传底层（CKGenome v3）

### 3.1 结构

- v8.7 的 5 个孟德尔位点（hair / eyes / brow / ears / mark）与多基因面型、体型**原样保留**，`CKGenome.LOCI`、显性序、1.5% 突变都不变。
- 新增 `genome.sig`，每国一个签名位点，`genome.v = 3`：

| 位点 | 国 | 类型 | 等位（显性高→低） / 数值 |
|---|---|---|---|
| `sig_ashbanner` | 灰烬邦 | 二倍体 | river_chart > chart_trunk > none |
| `sig_shuoying` | 朔影国 | 二倍体 | eclipse（不完全显性，杂合强度 0.45）/ none |
| `jade` | 清河国 | 数值 0–1 | 王 ≥0.72 · 贵 ≥0.48 · 潜 ≥0.40 |
| `sig_lantern` | 灯市联 | 二倍体 | filament > glass_sheen > none |
| `sig_frostcrown` | 霜冕廷 | 二倍体 | rime_tip > none > rime_lash |
| `sig_emberold` | 余烬旧邦 | Y（仅男性一份） | kiln_crackle / none；贵胤小征取 `mark.ember_sigil` |
| `sig_saltmarsh` | 盐泽盟 | X（女两份、男一份） | tide_ring > salt_band > none |
| `sig_irongorge` | 铁峡领 | 二倍体 + 外显骰 | gorge_split（外显 60%）> brow_notch > none |
| `sig_starriver` | 星津邦 | 二倍体 | san_tai、si_fu（各自显性；兼得 = 七星） |
| `glow` | 南泽邦 | 数值 0–1（母系） | 王 ≥0.66 · 贵 ≥0.36 · 潜 ≥0.25 |

- **只失不得的突变**：签名位点每次传递有 0.4% 丢失为 none，**永远不会凭空长出冕征**。冕征只能遗传而来，因此「凭空显冕」本身就是伪胤证据。
- **不扰动旧随机流**：`founder()` / `cross()` 先按原顺序抽 v8.7 位点，签名位点用从调用方 RNG 状态派生（不推进）的子 RNG 抽取。`CKBloodline.LOCUS_ORDER` 仍是原来的十个冕征位点，排在最前，顺序不许改。多征位点写在 JSON 的 `trait_order` 里，接在这十个之后。因此前十个位点的抽取次数不变，`GENOME PASS silver=0.237 midparent_width=0.064`、`KINSHIP PASS mean=0.839 silver_skip=0.156` 与 v8.9 主干完全一致。调换 `trait_order` 只会重抽这些新征。
- **签名集不进政治。** `signatures()`、继承、王技、酒馆标价仍只看各国那一个冕征位点。发、虹膜、骨相、肤、体态、衣冠和纯血表情走 `express_trait()`，只进肖像、战吼和 3D 调色。详见 §11。
- **开局者（founder）**：按 `blood_mix` 权重为每个位点抽一条来源血胤，再按该血胤的基因型表抽基因型；数值位点取血统加权均值 + 噪声。流裔（exile）强制使用本家表，所以两成五血统的窑冕流裔照样满脸冰裂。

### 3.2 十律与 Punnett 速查

| 律 | 规则 | 例 |
|---|---|---|
| 觉醒律 | 显性携因，但须立功：伯爵及以上，或「旗誓」「冠线」荣衔 | 携因 × 无：50% 携因；觉醒看本人功勋 |
| 剂量律 | 一份弦朔、两份全朔 | 弦 × 弦：全朔 25% · 弦 50% · 无 25% |
| 阈值律 | 子 = 父母均值 + N(0, 0.06) + 15% 向本人血统均值回归 | 玉牒 × 玉牒 ≈91% 玉缕；玉牒 × 汀洲 ≈0% |
| 显性律 | 一份即显 | 灯丝/无 × 无：50% |
| 隐性律 | 两份才显；霜梢眉为显性小征 | 携 × 携：霜睫 25% |
| 父传子律 | 父亲的 Y 原样给每个儿子 | 冰裂父：子 100% · 女 0% |
| 父传女律 | 父亲的 X 给每个女儿；母亲给一半 | 潮痕父：女 100% · 子 0%；杂合母：各 50% |
| 外显律 | 显性，出生时掷外显骰，60% 显 | 峡眉纯合父 × 无：携 100% → 显 60% / 藏钢 40% |
| 互补律 | 三台、四辅各自显性；兼得为七星 | 三台纯合 × 四辅纯合：七星 100%；七星 × 七星：50% |
| 母传律 | 子女萤值 = 母亲萤值 + N(0, 0.07)；父亲为零 | 萤母之子 100% 发光；萤子之子 0% |

`CKBloodline.forecast(father, mother)` 给出精确概率（离散位点枚举、X/Y 分性别、数值位点正态近似），联姻界面「子嗣期望」卡第三行显示，例如「峡眉 60%；潮痕发 女 100% · 男 0%」。

### 3.3 遗留存档

- 旧 v2 基因组首次使用时 `CKBloodline.upgrade_genome()` 按 id+姓名种子补签名位点（确定性）。
- v8.7 `mark.crown_rime` 的拷贝数（0/1/2）直接写成 `sig_frostcrown` 的 rime_lash 拷贝数：老存档里显霜冕印的王胤，v89 显霜睫；携带者仍是携带者。
- 四条 v8.7 血胤 id（`common_ash`、`river_ward`、`ember_noble`、`frost_crown`）保留：六维区间与 `bloodlines.json` 一致（CI 校验），面型/体型/肤色均值与 `CKGenome.BLOOD` 一致（Godot 测试校验）；等位权重按反套路锁调整（霜冕王胤去掉 wheat、去掉 crest 与 crown_rime）。

## 4. 十国详案

> 每国：王胤 / 贵胤 / 民胤 · 冕征阶梯 · 血律 → 继承法 → 危机 · 联姻外交 · 边血 · 衰落与复兴 · 伪胤与验证 · 流裔 · 王胤专属战技。六维区间、基因表、提示词全文见 JSON。

### 4.1 灰烬邦 · 烬图王胤（觉醒律）

- **三胤**：烬图王胤（烬图氏，灰座旧王）· 旗帅贵胤（白垣旗帅诸家）· 灰烬民胤（陆桥边民，v8.7 `common_ash`）。
- **视觉阶梯**：民胤 8% 携「潜图」→ 旗帅颈侧一道淡银紫「旗痕」（隐征）→ 觉醒后左颈完整「河图纹」，像平原河网图（明征）。中国文化里的「河图」直接成为王座的图腾。
- **血律 → 继承**：携因不显，必须立功。灰座空了一百年，**每一代都要重新打出来**。陆桥议会在觉醒者中「擎旗公推」（勋位×10 + 荣衔×3 + 等级）；分数相近即「议会分旗」。
- **灰旗的百年主线**：家主出生即携半张河图（`旗嗣印`），**灰烬邦邦交达到「盟誓」时家主立「旗誓」**（`banner_oath` 荣衔），携因者当场觉醒：颈侧河图燃起、获得「燃图号令」、清单里的肖像提示词随之改变（农场据此重绘该 unit_id）、具备议会公推资格。
- **边血**：「灰边」，无污名（佣兵之国不问出身）。
- **伪胤**：「伪图」——颜料画的颈纹（肖像破绽：墨边晕开）。祠堂「燃香验图」，同时报出潜图携因。
- **流裔**：烬图流裔（陆桥、灰烬邦、星津的驿城，多半自己都不知道携着潜图）。
- **战技**：燃图号令——全队防御 +3，自身本回合无视控制地带。

### 4.2 朔影国 · 朔望王胤（剂量律）

- **三胤**：朔望王胤（朔氏，夜阙）· 夜阙贵胤（多为一份朔因）· 霜脊民胤（北境山民，8% 一份）。
- **视觉阶梯**：弦朔瞳（瞳缘一弯银弦，隐征）→ 全朔瞳（整圈细银环，日全食，明征）。剂量直接写在眼睛里。
- **血律 → 继承**：「全朔为尊」，全朔先于一切弦朔，与长幼无关。年幼的全朔越过年长的弦朔者，即「弦朔之乱」；两位全朔年岁相仿则「夜阙分烛」。
- **政治**：两位夜阙卿结婚，四个孩子里就可能出一位全朔，所以宫廷什么都不信，只信眼睛；夜禁婚令让朔因只在宫内流转。
- **联姻外交**：与朔氏或夜阙卿联姻，朔影邦交大涨（贵胤 +13、王胤 +18），灰烬邦 −2（陆桥议会不安）。这是化解灰旗世仇的正面路线。
- **边血**：「弦外」，重度污名：有朔血而眼无银弦者不被承认，在朔影酒馆还会被压价。
- **伪胤**：「画瞳」——琉璃镜片（破绽：瞳外缘镜片反光）。「暗室验瞳」：真朔环在全暗中微亮。
- **流裔**：影裔（夜阙清洗中逃出的弦朔者，在港口做斥候、刺客）。
- **战技**：朔夜凝视——伤害 +25%、命中 +12，令目标破防 3。

### 4.3 清河国 · 玉牒王胤（阈值律）

- **三胤**：玉牒王胤（澜氏）· 河卫血胤（掌渡口的世家，v8.7 `river_ward`）· 汀洲民胤（三角洲与雾中果林）。
- **视觉阶梯**：玉值 ≥0.48 发间「玉泽」（隐征）→ ≥0.72 左鬓「玉缕」，通透如软玉（明征）。
- **血律 → 继承**：玉缕是许多细小血脉叠起来的「玉值」。书院记谱（玉牒）、算婚；「牒序」按玉值排座，差距 <0.03 即开「牒议」，谱上做手脚即「改牒」。牒外一次通婚就能让下一代失去玉缕——这就是门阀政治的遗传学版本。
- **边血**：「牒外」，重度污名，不得任官。
- **衰落与复兴**：外婚把玉值拉回平均；偶发高值的「玉缕返照」须过书院牒议才算数。
- **伪胤**：「染缕」——染坊染出的玉色发（破绽：发根发黑）。「牒验」对谱看根。
- **流裔**：澜氏旁支（因改牒丑闻除名，在盐泽做盐引公证人，牒外三代只剩玉泽）。
- **战技**：玉牒清音——治疗相邻友军 10–14，全队防御 +1。

### 4.4 灯市联 · 灯冕王胤（显性律）

- **三胤**：灯冕王胤（琉氏，灯座）· 琉商贵胤（琉璃商行）· 潮灯民胤（群岛水手与夜市人家）。
- **视觉阶梯**：「琉光」（发梢虹彩琉璃光泽，隐征）→「灯丝发」（发梢化作琉璃纤丝，末端冷白微光，明征）。
- **血律 → 继承**：显性让灯丝在港口泛滥，人人有血统，于是灯座每七年拍卖（「灯会竞座」，以爵位×10 + 等级为身家代理）。三人以上同时出价即「满港竞价」；座主破产即「熄灯」。
- **纸冕**：灯市出售「灯籍」（男爵 160 / 伯爵 420 银，邦交「友善」起）。持灯籍者有冠饰（「新铸得过分崭新的琉璃徽」）而无灯丝；霜冕、清河、朔影的王/贵胤拒绝与纸冕者联姻（`marriage_barrier`）。
- **联姻外交**：娶灯丝者附嫁妆（贵胤 40 / 王胤 120 银）——「嫁妆比血重」。
- **边血**：无（「钱即血统」）。
- **伪胤**：「假灯丝」——琉璃纤维接发（破绽：发梢夹扣接缝），伪胤率 ×1.5 全国最高。「灯验」：霜灯下真灯丝折出光谱。
- **流裔**：熄灯裔（破产灯主后人，发梢仍是灯丝，钱袋空了）。
- **特例**：唯一一个**不需要邦交就能在港口酒馆遇到王血**的国家（显性律让王血不再稀罕）。
- **战技**：琉灯幻步——脱离无代价、拆交战锁定，下一击暴击 +12。

### 4.5 霜冕廷 · 霜冕王胤（隐性律）

- **三胤**：霜冕王胤（v8.7 `frost_crown`，六维上限 20）· 霜阙贵胤（廷卿）· 高原民胤（牧户与冰匠，10% 携霜睫）。
- **视觉阶梯**：「霜梢眉」（眉尾一点霜白，显性小征，隐征）→「霜睫」（睫毛与眉梢天生霜白，与发色无关，明征）。
- **血律 → 继承**：两份才显，携者外表无异。「冰钟默选」：廷议在霜睫者中静默推举（意志×5 + 年龄）；一个都没有即「候冕之年」，摄霜理政等隐性复现。
- **联姻外交**：祠堂开出的「携霜」验契是霜冕最硬的聘礼——你的孩子只要验明携因，霜冕就会坐下来谈。

- **伪胤**：「敷霜」——睫上白粉（破绽：结块），伪胤率 ×0.6。「呵气验睫」。

- **战技**：冰钟静域——治疗相邻友军 6–9，全队防御 +2。

### 4.6 余烬旧邦 · 窑冕王胤（父传子律）

- **三胤**：窑冕王胤（焚氏，旧邦窑王）· 余烬贵胤（烬议诸家，v8.7 `ember_noble`）· 窑原民胤（窑镇与废墟掘客）。
- **视觉阶梯**：「烬纹」（v8.7 `ember_sigil`，不完全显性，由 `CKGenomePortrait` 的 mark 位点描述，隐征）→「冰裂纹」（左鬓到颧骨一片青瓷开片，皮肤微有瓷光，明征）。哥窑开片是中国瓷器最有辨识度的语汇之一。
- **血律 → 继承**：冰裂纹随 Y 父传子。「旧典承窑」长子承座；无一个冰裂之子即「冷窑」；冰裂之子缺席而窑女在场即「典争」（旧典派 vs 新典派）。
- **冒窑**：冰裂之子的父亲没有冰裂——Y 连锁让「父不是父」成为可验证的丑闻。
- **衰落与复兴**：末代窑王只有女儿，窑冕被视作断绝；三代前被逐出焚阙的幼子一支（窑冕流裔，血统只剩两成五，冰裂一分不少）是唯一火种。**若灰旗之中有冰裂男子生子，窑冕便归于灰旗。**
- **边血**：「冷灰」（窑女之子），轻度污名。
- **伪胤**：「描釉」（破绽：开片过于规整）。「温瓷验纹」：真冰裂遇热透出瓷光，并核对父系。
- **战技**：窑火重铸——伤害 +60%、命中 +5，击退目标。

### 4.7 盐泽盟 · 潮后王胤（父传女律）

- **三胤**：潮后王胤（汐氏，盐后）· 盐引贵胤（握盐引的世家）· 芦滩民胤（潮滩盐户）。
- **视觉阶梯**：「盐线发」（一道淡盐白横线，隐征）→「潮痕发」（等距盐白发环，像潮水留在盐滩上的圈痕，明征）。
- **血律 → 继承**：潮痕随 X 显性而行——潮痕男子传给**全部女儿、不传儿子**。「潮法传女」由潮痕之女承座，潮痕男子称潮伯，只掌兵。同一位潮伯的几个潮痕女儿出自不同母亲，即「众女潮」。
- **复兴**：女王只生儿子时王座看似中断；但潮痕之子把潮痕全部传给女儿——「潮回」，王座隔一代跳回来。
- **边血**：「退潮」（潮痕男子的儿子承不到潮痕），轻度污名。
- **伪胤**：「盐染」漂白（破绽：发环边缘毛边）。「卤水验发」并核对父母：无潮痕的父母生不出潮痕女儿。
- **流裔**：潮伯（潮痕男子出海从军，**酒馆里能遇到显冕的男王血**）；离潮支（盐战落败的女系，隐居南泽）。
- **战技**：潮汐律令——占据地利（地形加成翻倍），全队防御 +2。

### 4.8 铁峡领 · 峡钢王胤（外显律）

- **三胤**：峡钢王胤（锻氏，峡座）· 峡卫贵胤（守三层吊桥）· 炉峡民胤（峡谷锻炉匠户）。

- **血律 → 继承**：峡眉因显性，但只有 60% 携者外显；其余是「藏钢」，照样传给子嗣。「锻选」：所有经祠堂验明的携因者（显或藏）都能进锻场，力 + 体 + 等级最高者胜；藏钢夺魁即「藏钢之争」，三层城区旗鼓相当即「三层分锻」。
- **玩法**：酒馆里的炉峡民胤有 4% 携峡眉之因；一个眉形完整的铁匠儿子，验血后可以被送进锻场。
- **边血**：「无刻」，无污名（只看锻场）。
- **伪胤**：「剃眉」（破绽：眉隙里新长的短毛）。「斋月验眉」。
- **流裔**：断桥裔（历次锻选的败者）。
- **战技**：断峡横扫——伤害 +40%，对重甲额外 +5，波及相邻 35%。

### 4.9 星津邦 · 七星王胤（互补律）

- **四胤**：七星王胤（星枢氏）· 东虹贵胤（三台）· 西虹贵胤（四辅）· 津桥民胤。首都「双虹」的两座虹桥就是两家。
- **视觉阶梯**：「三台痣」（左眼下三颗斜列小痣）/「四辅痣」（左鬓四颗弧列小痣）（隐征）→「七星痣」（左颧到鬓北斗七痣，明征）。
- **血律 → 继承**：三台与四辅在同一人身上合成七星，所以东虹只有三台、西虹只有四辅，两家必须世代联姻。「双虹合璧」：唯七星者可登星枢（感知 + 意志排序）；无七星即「孤虹」，观象台摄政。
- **玩法**：撮合三台家与四辅家（或让你的孩子各携一种），就能制造七星——星津是外交上最友好的国家，也是最适合「育种」的国家。
- **边血**：「残星」，轻度污名。
- **伪胤**：「点痣」（破绽：痣距与星图不合）。「星验」：观象台按标准星图比对。
- **流裔**：坠星支（政变后流亡的七星王子后裔，在清河书院做学者佣兵）。
- **战技**：北斗定星——伤害 +30%、命中 +15，无视地形回避。

### 4.10 南泽邦 · 萤母王胤（母传律）

- **三胤**：萤母王胤（萤母诸氏）· 渡灯贵胤（掌渡口灯火的氏族）· 雾林民胤（养蜂人与伐木人）。
- **视觉阶梯**：「萤痕」（鼻梁几点淡薄荷微光，隐征）→「萤斑」（鼻梁与上颊薄荷绿微光雀斑，雾里更亮，明征）。

- **联姻外交**：要光，得娶萤母的女儿；萤母难得外嫁（规划：须「萤约」，一位孙女归林）。
- **伪胤**：「磷粉」（破绽：光点边缘晕开）。「雨验」并核对母系：母亲无光，孩子不可能有光。

### 4.11 朔澜陆桥（地区，无王座）

## 5. 跨国系统

### 5.1 酒馆池（`CKBloodline.roll_recruit`）

| 城镇类型 | 民胤权重 | 贵胤权重 | 流裔概率 |
|---|---|---|---|
| 都城 | 5 | 3 | 12% |
| 城 | 6 | 2 | 10% |
| 镇 | 6 | 1.5 | 8% |
| 港 | 5 | 1.5 | 25% |
| 要塞 | 5 | 2 | 6% |
| 村 | 8 | 0.4 | 4% |
| 本堡酒馆 | 6 | 1.5 | 25% |

- **王胤门槛**：只在都城出现，城市声望 ≥30 且邦交 ≥55，权重 0.8（灯市例外：都城/港/城、无门槛、权重 0.5）。
- **盟誓**：邦交 ≥80 时，都城第一席必为本国王胤，且由国家担保、不会是伪胤（兑现 `NATION_UNLOCKS[4]`「该国都城酒馆出现本国最高血脉」）。
- **贵胤混血**：30% 贵胤是「贵 75% + 本国民 25%」；王胤一半混入本国贵胤 30%。
- **伪胤率**：贵胤声称 10%、王胤声称 25%，乘以各国伪造倍率（灯市 1.5、清河/星津 1.2、霜冕 0.6……）。
- **流散表**（`diaspora`）：萤子 1.0 · 潮伯 0.6 · 烬图流裔 0.5 · 熄灯裔 0.5 · 影裔 0.4 · 窑冕流裔 0.35 · 雪逐支 0.3 · 断桥裔 0.3 · 澜氏旁支 0.2 · 坠星支 0.15 · 离潮支 0.1；每条列出出没的国家与性别（萤子、窑冕流裔、潮伯只有男性）。
- **职业偏向**：本堡酒馆 60% 取血胤偏好职业（`jobs`）；城市酒馆再与该国 `world_v87` 职业表各占一半。

### 5.2 定价（`World.hire_cost = 28 + 爵位×15 + CKBloodline.hire_premium`）

- 王胤声称：基础溢价 ×「证明系数」——显明征 1.0 · 显隐征 0.75 · **无征 0.5（无征之冕半价）**。
- 贵胤声称：显小征 1.0，否则 0.8。
- 民胤：基础 0；若身上有**明征王冕**，老板加价 +40。
- 边血：在重度污名国（朔影、清河、霜冕），非王胤声称者再减 8。
- 王胤基础溢价：七星 135、朔望 130、窑冕 125、玉牒 120、潮后 115、霜冕 110（与 v8.7 一致）、峡钢 100、萤母 95、烬图 90、灯冕 80。

### 5.3 伪胤与祠堂验血

- 伪胤（`blood_meta.pretend`）：血统写着贵/王胤，六维与基因来自真实民胤；酒馆按声称收费；**肖像带伪造破绽**（染缕的黑发根、假灯丝的接缝……），眼尖的玩家看画就能识破。
- 祠堂「验血」（城堡 → 祠堂 → 右下「祠堂验血」，快捷键 V）：每人 `max(6, 14 − 2×祠堂等级)` 银。结果写入族谱纪事并记 `blood_meta.verified`：
  - 揭出潜征（潜图、携霜、藏钢、近槛玉值）；
  - 拆穿伪胤并把血统改回真实民胤；
  - 父母一致性：冒窑（Y）、伪潮（X）、伪萤（母系）、伪朔（剂量）、伪星（互补）。
- 验过者：潜征在 UI 中显示为「·潜」；藏钢可入锻选；携霜契可议霜冕婚（规划）。

### 5.4 边血矩阵（`CKBloodline.edge_blood`）

王血 ≥1/8 而不显该国王冕即边血。污名：灰边 0 · 无刻 0 · 灯市无 · 冷灰 1 · 退潮 1 · 残星 1 · 熄萤 1 · 弦外 2 · 牒外 2 · 薄霜 2。重度污名影响该国酒馆定价，族谱档案显示称谓；出生时若成边血，族谱记一笔（「X 有某某之血而无其征，人称『熄萤』」）。

### 5.5 双冕

一个孩子同时显出两国王冕（不同位点互不干扰），例如铁峡锻王 × 盐泽潮后的女儿：峡眉 + 潮痕发（见 fixture `heir_dual_crown`）。双冕者在两国都有继承资格，是外交筹码也是危机磁铁；出生时族谱记「双冕」。

### 5.6 近亲护栏与纸冕

`Lineage.can_propose` 新增 `CKBloodline.marriage_barrier`：
- 三等亲以内（父母子女 1、兄弟姐妹 2、叔侄 3）宗祠不许；堂表亲（4）允许。
- 纸冕者与霜冕、清河、朔影的王/贵胤之间不许联姻。

### 5.7 联姻外交（`Lineage.marry`）

配偶血胤所属之国邦交：民 +2 · 贵 +5 · 王 +10；贵/王胤再叠加各国条款（朔影 +8 且灰烬邦 −2；灰烬邦 +2 且陆桥 +1；星津 +3；其余本国 +2）；灯市贵/王胤附嫁妆 40 / 120 银。婚宴消息列出邦交变化。

### 5.8 继承评估器（`CKBloodline.succession`）

输入候选人，输出按本国继承法排序的承座顺序与危机（见 §2.4 危机列）。规则在代码中逐国实现，测试覆盖弦朔之乱、典争、冷窑、众女潮、藏钢之争、候冕之年。

### 5.9 王胤专属战技

10 个技能写在 `skills.json`，`jobs: []`、`tree: "blood"`、带 `blood_sig`，只复用战斗代码已处理的字段（dmg_mul、hit_mod、expose、push、cleave_pct、vs_tank_bonus、ignore_terrain_avo、heal、party_def_buff、def_buff、leave_free、ignore_zoc、clear_combat_lock、terrain_ward、next_crit_bonus），**战斗系统零改动**。`GameState.grant_job_skills` 末尾调用 `CKBloodline.sync_signature_skills`：显冕即得，失冕即去；技能树界面不显示（不能用战技点学）。

## 6. Plan A 肖像管线

- **构建器归属**：`CKGenomePortrait`（PR #1）负责种子、基础描述、清单导出与入库。本系统**只通过 `CKGenomePortrait.set_bloodline_clause_hook` 注册一条子句**：`GameState._ready` 注册 `Callable(CKBloodline, "portrait_clause")`，`_exit_tree` 注销（静态钩子不能活过引擎拆脚本）。
- **风格锁**：`style_lock_path()` 优先读 `docs/art/style-lock-v89.json`（继承 v8.7 调色、光照、质感；前缀 `CenturyKnights style lock v8.9:`；负面词追加反套路项）。
- **子句结构**（`Bloodline: …`）：
  1. 显出的冕征（王/贵，含取景提示，例如河图纹附「领口左侧敞开」）；
  2. 已显出的签名集，按国家收成一句：`{name_en} trait set, {youth|prime|elder}: …`。青年 / 盛年 / 晚年用各征自己的三句提示词。两个及以上国家同时显征时加 `mixed blood, both houses visible on the same face`，并收一句风格锁（哑光工艺布、磨砂金属、冷白主光、至多一针薄荷）；
  3. 伪胤的伪造破绽（未揭穿时）；
  4. 主血胤的地域服饰（只写衣着，不写任何冕征相关的光线或取景）；
  5. 冠饰：纸冕徽 > 流裔「旅途磨旧、无家徽」> 在位王/贵胤（男爵及以上）的本国冠饰；
  6. 子嗣：「heir of a father from the Iron Gorge royal line and a mother from the Saltmarsh royal line, with the tide-ringed hair from the mother's line, the gorge-split brows from the father's line, the father's eye colour…, a clear family resemblance」。冕征按血律归因（母系→母、Y→父、其余看父母谁携带），发色/瞳色/眉形只与一方父母相同时写出。
- **3D**：`UnitModel.resolve` 只附加调色十六进制和 `regalia_*` 模块 id，不新增网格。衣冠征没显出来（纸冕、伪胤、未到龄）就不挂模块。体态征的 `bark` 写入 `bark_zh`。

## 11. 多征签名集（v8.9.2）

王族不该只有一个胎记。每国王胤是 **6–8 个互相咬合的征**，各自挂在一个基因组位点上，遗传律彼此不同。贵胤拿走其中 3–5 个（王室的弱回声 + 自己的一个征）。民胤 2–3 个地域征，不借用王室等位。

**为什么要拆开。** 一个征只能告诉你「像不像这家人」。一套征才能让混血在脸上拼出来：父亲的虹膜、母亲的肤、两边都留下的骨相。稀释的王血只剩残套。伪胤可以描明征（染缕、假灯丝），描不出要近看的隐征；祠堂对等位，眼尖的人看缺了哪一笔。纯血表情要本冕已经显出、并且两份纯血等位同时在，所以满血是看得见的，不是百分比。

**随机流。** 新位点写在 `trait_order`，接在原来的十个冕征位点之后，用同一把分叉 RNG。前十个位点的抽取次数与顺序不变，v8.7 的发色瞳色也不动（它们在分叉之前）。因此 `GENOME` / `KINSHIP` 的旧数字保持原样。调换 `trait_order` 只会重抽这些新征。

**年龄。** 每条征有青年 / 盛年 / 晚年三句提示词。年觉律的征在到龄之前是潜征，肖像不画。纯血律的征默认不进「盛年王胤」示例，只有两份纯血且本冕已显才出现。

**3D。** 只给调色和冠饰模块 id（`regalia_*`），不新增网格。模块在遗传到衣冠征时才挂上。纸冕、伪胤没有这些 id。

|---|---|
| 显性 / 隐性 / 外显 | 发、虹膜、体态；外显约六成，其余藏着照样传 |
| 父传女（X） | 朔影窄银领、霜冕冷粉灰、盐泽海玻璃瞳、星津左上视 |

| 母传 | 清河青灰肤、盐泽盐光、南泽苔缘瞳 |

## 10. 各国王族冕征一句话

- **灰烬邦 · 河图纹**：左颈一张银紫色的河网图，立了大功才会亮起来。
- **朔影国 · 全朔瞳**：极深的瞳仁外一圈细银环，像日全食；一份因只有一弯银弦。
- **清河国 · 玉缕**：左鬓垂下一缕通透的玉色发，玉值不够就只剩一层玉泽。
- **灯市联 · 灯丝发**：发梢化作琉璃纤丝，末端泛冷白微光。
- **霜冕廷 · 霜睫**：睫毛与眉梢天生霜白，与发色无关。
- **余烬旧邦 · 冰裂纹**：左鬓到颧骨一片青瓷开片，只传儿子。
- **盐泽盟 · 潮痕发**：发丝上等距的盐白细环，像潮水在盐滩留下的圈痕。
- **铁峡领 · 峡眉**：双眉被一道天生的窄隙劈开，像俯瞰的峡谷；四成携者看不出来。
- **星津邦 · 七星痣**：左颧到鬓七颗小痣排成北斗，要东虹三台加西虹四辅才凑得齐。
- **南泽邦 · 萤斑**：鼻梁与上颊薄荷绿的微光雀斑，只从母亲那里来。
