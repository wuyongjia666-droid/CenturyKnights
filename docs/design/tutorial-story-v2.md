## 0. 结论

现在的第零章「骨架对、魂没了」：19 拍的选择和旗标都在，但原著的**动机线**（爹被划掉的那一行 → 想要一个划不掉的字 → 字是划得掉的，划不掉的是身后站着谁）被压成了几句旁白；原著里**最动人的三场**（景伯夜访、隘口里晚担把你撞进车底、回石垒坡拿鞋）完全没有；**战斗教学**是三张与故事无关的「交战锁定」提示卡，和小说里「选落点、选了就站着」毫无关系；**结尾**是一个按钮写日志，没有回报。

v2 的做法：
1. 动机线三次出现、一次兑现：开场（爹被划掉）→ 写字（「哪个字划不掉？」）→ 香盏（「划不掉的，是写字的时候身后站着谁」由主角亲口说）。
2. 每个机制都放进一个原著场景里教，由场景里的人说出来，不再弹无关教学卡：
   落点/站位 = 灯影在地上画路；交战锁定 = 晚担把你撞进车底；别追 = 推到第二辆车就停；
   雇人/月饷 = 掌柜 + 渠的空圈账本；委托 = 管事「它让你活到出名那一天」；赶路/粮 = 三天药材路；
   联姻期望行 = 使者「念不下去，就不要点头」；月份推进 = 十个月；结算 = 「粮饷簿不认眼泪」。
3. 补四个新拍（夜访、隘口回声、回石垒坡、手记）和章节标题卡，结尾给回报：商队念你的姓 + 你的手记 + 三颗伏笔（半个环的签、白垣的另一截杆、青禾的河图未亮）。
4. 横屏手机可读：对白框按视口锚定、永不截字；点屏幕任意处推进；常驻「跳过」按钮（48dp）；中途存档按拍恢复。
