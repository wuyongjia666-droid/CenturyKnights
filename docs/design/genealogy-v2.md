# 族谱 v2：头像总览 + 个人谱系详情

## 为什么改
旧族谱把全族画成一棵树：家主一行、团员一行、二代挂在下面。孩子一多就挤出画面，手机横屏上更是点不到、看不全。

## 两个页面
1. **族谱总览** `scenes/hub/lineage_view.tscn`
   - 左侧：头像网格，一人一格（头像、名字、年龄段）。家主排第一，其后按辈分、年龄排。网格放在 `ScrollContainer` 里，手指拖动即可滚动。
   - 右侧：信息面板（`CKLineageInfo`）：立绘、名字、年龄、族徽、爵位徽章、职业、禀性，底部「详情」按钮。
   - 点头像只更新右侧面板，不跳页。
   - 底部保留原来的跳转条（血脉图鉴 / 血脉详档 / 朝报 / 生育节奏），节点名 `LineageJumps` 不变。
2. **个人谱系** `scenes/hub/lineage_tree.tscn`（参数 `{"focus": 人物 id}`）
   - 以此人为中心的三层：上层父母，中层本人与配偶，下层子女。
   - 点任一节点：右侧面板换成此人；面板里的按钮变成「以此为中心」，点了重画谱系。
   - 画布可单指拖动平移，双指捏合 / 滚轮缩放（0.5–2.0）。

## 状态
- **空族谱**：没有任何族人时，网格位置显示「尚无族人」说明，右侧面板显示占位，「详情」不可用。
- **亡故**：头像灰化并标「故」，信息面板写「已故」，仍可进详情。
- **人多**：网格滚动；谱系页子女一行排开，超出画面靠拖动/缩放查看。
- **返回（CKNav）**：总览用 `CKNav.go` 进详情；详情页 `nav_back()` 走 `CKNav.back` 的栈弹出回总览；总览 `_back()` 回城堡（序章 0.5/0.55 节拍仍回剧情）。

## 手机横屏
- 所有可点的东西 ≥ 48dp（头像格 112×132，按钮高 48）。
- 头像按钮 `mouse_filter = PASS`，拖动能传给滚动容器。
- 触屏上不显示键位提示（A / Y / ESC）。
- 不改全局的 `MobileLayout`，只改族谱两个场景和它们的脚本。
