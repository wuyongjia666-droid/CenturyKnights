# 术语表（v9.2.1，审查 P2-2）

界面、芯片、tooltip、帮助条目都用左列的写法。新增文案先查这张表。

| 统一写法 | 不再使用 | 说明 |
|---|---|---|
| 委托榜 | 委任榜、可交付委托、委托板 | 城堡与城镇的委托入口；待办芯片写「待战委托」 |
| 舆图 | 世界地图、地图 | 大地图。首次出现的帮助条目写「舆图（世界地图）」 |
| 回到这一章 | 继续主线 | 城堡主线按钮，旁边写章节标题（提案 §4.7） |
| 灰旗堡 | 城堡枢纽、主城 | 玩家的城堡；返回按钮写「回到灰旗堡」 |
| 团徽 | 城堡旗徽、队旗 | 佣兵团永久旗徽；家族用「族徽」 |

待定：导航牌匾「旗塾」还是「承习厅」（提案开放问题 3），由制作人拍板后补进本表。
