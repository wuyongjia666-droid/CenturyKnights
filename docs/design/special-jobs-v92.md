# 特殊职业落地（v9.2 §4.2）

结论：六门特殊职业全部开放。每门要在指定城盖印（现职=前置二阶、人在印城、声望≥30、本城之事已办），战斗规则一句话说清，battle_controller 只接四个钩子。

## 规则（与提案对照）
| 职业 | 前置 | 印城 | 落地规则 | 与提案差异 |
| --- | --- | --- | --- | --- |
| 验盏 | 祭司 | 灯都·琉光 | 本场第一次打中的敌人点盏，全队打它 +8（伪造）/+4（无血谱）/0（真血谱） | 不手动指定，第一次命中即指定 |
| 桥税骑 | 轻骑 | 西桥头堡 | 每场一次：回合开始站在桥上且挨着敌人，自动拦第一个：它下回合移动 −2，自己本回合 +1 | 自动触发，省一次点按（手机） |
| 录外生 | 秘术士 | 上河书院 | 本场第一次战技不进冷却 | 无 |
| 霜候 | 咏者 | 冕都·霜阙 | 我方回合开始，相邻且站丘/垒的一名敌人防御 −1，直到它挪窝；每回合一人 | 无 |
| 盐引 | 旗手 | 盐都·晶垣 | 开战时粮 ≥ 当日口粮，相邻友军整场防御 +1；不够则不开、不扣士气 | 无 |
| 锻眉 | 勇士 | 谷底市 | 本场第一次受伤：攻击者 −2 血，自己防御 +2 到战斗结束 | 无 |

## 门槛的简化
提案的「生平门」（习痕或成人差事）先用「本城之事已办」代替差事；习痕免差事暂不区分。「该职业下至少打过一场」暂不检查。三阶职业不设城门。

## 实现
- `CKSpecialJobs`（scripts/battle/special_jobs.gd）：`on_player_turn` / `strike_mods` / `after_strike` / `skip_cooldown`。
- battle_controller 四行：`_start_player_turn`、`roll_attack` 前、扣血后、`_consume_skill`。
- 本场状态放在对象 meta，不进存档；移动增减经 `CKCharacter.derived_move()` 读 `battle_move_mod`。

## 状态
- 空：队里没有该职业 → 钩子什么都不做。
- 失败：粮不够 → 盐引不开并写日志；不在桥上/没相邻敌人 → 桥税骑不触发，留到下回合。
- 重复：桥税骑、录外生、锻眉每场一次；霜候同一敌人不挪窝不重复记。
