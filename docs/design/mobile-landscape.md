# 手机横屏适配（mobile-landscape）v1

## 结论
手机上一律真全屏：画面铺满整块屏（含挖孔区域的背景），可点内容避开安全区；不再出现 1280×720 居中竖条加左右黑边。

## 契约
1. **拉伸**：`stretch/mode=canvas_items`，`aspect=expand`。逻辑短边固定 720，长边随屏幕变长（2400×1080 → 1600×720）。
2. **根节点**：`MobileLayout.fit` 让场景根节点占满安全区（size = 安全区 / scale），不再按设计尺寸居中。场景内部必须靠锚点（全屏、靠边）布局，不得写死 1280 宽。
3. **沉浸**：Android 导出 `immersive_mode=true`，横屏锁定（orientation=4 sensor landscape），返回键走 CKNav，不弹暂停菜单到建团等表单页。
4. **战斗 HUD（第二个 PR）**：棋盘占满高度；右侧窄单位卡；行动按钮贴底不遮棋盘；教学提示单条、可关、不叠字；双指缩放、单指拖动平移。
5. **最小尺寸**：可点控件 ≥48dp，正文字号 ≥12dp。

## 门禁（永久）
- `scripts/mobile_gate.sh`：Xvfb 下以 `CK_FORCE_MOBILE=1` 在 2400×1080、2340×1080、1920×1080、2560×1600 渲染标题、城堡、各分页、舆图、战斗、设置；`tools/ci/mobile_gate.py` 检查：四边无黑条、控件不出屏、文字控件不重叠、按钮 ≥48dp、字号 ≥12dp；生成 contact sheet。
- 安卓发版前额外跑真机模拟器冒烟（2400×1080 横屏 AVD，adb 点击走主流程 + 每页返回键，截图 + logcat）。任何黑边、裁切、卡死、崩溃都阻止发版。

## 空/失败/重复状态
- 无安全区信息（桌面/旧机）：insets 为 0，照常铺满。
- 平板 16:10：短边按宽度缩放，长边仍铺满。
- 反复旋转/切后台：`size_changed` 触发重新 fit，结果按 key 去重。
