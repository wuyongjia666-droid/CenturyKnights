## 1. 签收定义（「做成了」相关口径）

三年终点是 **Android + Windows 商店同日 1.0**（Steam 稍后）。  
**Y1-A** 是 Year1 前半的手游硬门禁：战棋手感 + 端游/手游立绘对齐，**真机签字前不开内容季扩写**。

本清单过关的最低条：

1. 真机上「不难选中」、点按不偏、对话/枢纽不裁字、Forecast 横屏可读。  
2. 剧情 supporting 说话人半身立绘与 Windows **同档观感**（允许 medium vs large 略软 = 机制 B，不算失败）。  
3. 有 KVM 或真机代理时的 APK 冒烟过一遍（无加速 emulator **不算**）。

过关后：开内容季 #1 选题与小说；未过关：继续修，不扩写主线。

## 3. 真机必验（可勾选）

装 **同一 release / 同 commit** 的 Windows 与 Android 发行包。优先同存档、同对话节点、同教程战。

### 3.1 战棋选中手感「不难选中」

- [ ] 点**底座/脚圈** 10 次，成功选中 ≥ 8  
- [ ] 点**脸/头** 10 次，记下成功次数（作对照；脸难点是已知几何，见审计 §1.4，**本阶段不改 pick**）  
- [ ] 点选 → 点移动格 → 确认（或拖到格松手）全流程不卡手  
- [ ] 选中后慢点不会误出情报；故意长按仍可出情报（T-P1-1）

### 3.2 安全区 / 镜头

- [ ] 刘海/挖孔侧点格子：落点与手指一致，不偏一个内缩（#334）  
- [ ] 捏合缩放后点选仍准；松手不误落子  
- [ ] 拖棋与拖地图不抢手势

### 3.3 对话板 / 枢纽布局（机制 C · 依赖 #339）

- [ ] 对白 **SpeakerPlate 名签**不被裁扁、不截半字  
- [ ] 枢纽 **「同袍」** 等 NavRail 旁标签不被裁切  
- [ ] 横屏 / 竖屏各扫一眼，无「有板无字」错觉

### 3.4 枢纽字号地板（依赖 #340）

- [ ] **城市场**等页无竖向挤扁字（解锁文案、阶梯标题可读）  
- [ ] market / estates / works / forge 扫一眼，无异常扁字

### 3.5 Forecast / 单位信息条（依赖 #341）

- [ ] 手机**横屏** Forecast 字号可读、不挤成一条线  
- [ ] 侧栏单位信息行高够点、够读

### 3.6 剧情立绘（机制 A 已合；九人已入库）

- [ ] ch0 等节点：supporting 说话人（如掌柜 / 稳婆 / 老旗手等）Android 为**半身**，非剪影  
- [ ] 与 Windows **同档观感**（允许 medium 比 large 略软 = 机制 B，**算过**）  
- [ ] 已知曾缺图的 9 人有板（非假图/占位色块）

## 4. APK 冒烟

- [ ] **有 KVM 的 CI / 机器**，或**真机 / 真机代理**，跑发行 APK 冒烟一遍  
- [ ] 记录：启动、进枢纽、进一战、进一段对白、退出无 ANR

**环境红线**（审计已写）：box 与 m173 **无 KVM / 硬件加速** → **禁止**再开无加速长跑 emulator。无加速冒烟**无效且伤机**。

自动化套件（`battle_feel` / mobile shots / 立绘门闩）只证代码契约，**不能替代**手指手感。
