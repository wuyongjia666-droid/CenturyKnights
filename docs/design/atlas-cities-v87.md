> 状态：已实现（v8.7 atlas 分支提交 b2454fa → e2e7d35 起）。数据由 `tools/world/gen_world_v87.py` 生成，内容在 `tools/world/world_content_v87.py` 手写。
> 运行时：`project/autoload/world.gd`（autoload `World`），UI：`scenes/hub/atlas_view.tscn`、`scenes/hub/city.tscn`。
> 美术：2026 当代奇幻 + Stitch 磨砂玻璃 UI；所有 Qwen 底图走 `docs/art/style-lock-v87.json` 的固定前缀/负面词，入库前过 `tools/art/style_check_v87.py`。拒绝中世纪羊皮纸风。

## 1. 设计目标

1. **舆图本身就是玩法**：十国 + 陆桥上每一处画出来的聚落都是可进入的节点；道路就是行军线；跑图消耗真实的“日、粮、银”，并推动城堡历法（衰老、俸禄、月度事件）。
2. **每座城都不一样**：名字、势力、规模、特产、传说、出产/求购、两件签名兵器、一条名誉委托——全部手写，不是随机词拼接。
3. **经济闭环**：城堡经济（粮/铁/药材/银）↔ 跑图消耗 ↔ 区域贸易差价 ↔ 铁匠铺材料 ↔ 委托报酬。
4. **战斗来自地理**：路遇、伏击、委托目标都生成**该地生物群系**的 SRPG 战场，敌人是**该国势力**的兵种模板。
5. **声望是钥匙**：城声望 + 邦交声望解锁更好的委托、铁匠铺扩建、签名与传奇兵器、价格优惠。

## 3. 世界结构

- **11 个区域**：灰烬邦、朔影国、清河国、灯市联、霜冕廷、余烬旧邦、盐泽盟、铁峡领、星津邦、南泽邦 + 朔澜陆桥。
- **74 个节点**：都城 10、城 9、港 6、要塞 13、镇 16、村 19、本堡 1（灰旗堡 hq）。每国 7 处，陆桥 4 处。
- **106 条道路**：国内道路 90（各带 1–4 危险度与日程）、国界关隘 14（收邦关税）、海路 2（船资 + 2 日，海上风暴事件）。
- **跨国只能经陆桥或海路**：西陆诸国 ↔ 陆桥西桥头堡 ↔ 陆桥驿 ↔ 东桥头堡 ↔ 东陆诸国。
- 节点字段：`id name nation kind size pos(板块归一化坐标) biome specialty lore produce demand smith_tier tavern_slots sig_items sig_quest`。

## 4. 跑图（Overworld Travel）

1. **选路**：点节点 → `World.route()`（Dijkstra，按日程）→ 预览：路线、日数、耗粮、关税/船资、最高危险度、经过的国界。
2. **启程**：`begin_travel`；UI 逐段 `step_travel`，旗标沿道路补间移动；离开当前板块时自动切换到目标国视图。
3. **每日结算**（`advance_days`）：每人每日 0.5 粮（向上取整）；粮尽 → 每日士气 −4；第 30 日翻月 → `Calendar.advance(1)` → 城堡月度结算（衰老、俸禄、生育、市集回补）。
4. **路段事件**：概率 = 0.22 + 0.12×危险度（护送中 +0.15），按道路类型、生物群系、国度过滤，伏击权重随危险度放大。
5. **遭遇战**：事件选择或委托目标触发 `start_encounter`：按节点生物群系从 maps.json 选底图（复制），按国度 `foes` 选敌人模板行（弱/近战/远程/首领），人数 = 2 + 危险度 + 战力层级修正；注册为 `wenc_<keyword>_<n>`，战斗结束回舆图。
   - 胜：缴获银两 + 当地材料，委托目标达成，继续未走完的路段。
   - 败 / 弃战：退回出发地，士气 −5，货物折损 1/4，护送委托失败。
6. **城堡**：灰旗堡是 hq 节点（进入 → 城堡大厅）。在别处时城堡页面视为“管家书信”远程处理，部队位置不变。

## 5. 城镇

| 页签 | 内容 |
|---|---|
| 概览 | 声望阶梯（陌生0 / 认识10 / 友善30 / 信赖55 / 盟誓80 及其解锁）、名誉委托、可在此交付的委托、贸易情报、主线标记 |
| 铁匠铺 | 本国制式线 + 本城签名兵器（◆三阶，需认识）+ 传奇（★四阶，需完成名誉委托且信赖）。详情：属性、对比当前装备、战技、适用职业、材料持有/需求；**购买**或**打造**（只付工钱 38% + 自备材料） |
| 市集 | 17 种货物：存货、买价、卖价、持有、已知最佳卖处（含差价），买1/买5/卖1/卖全；粮/铁/药材直接入城堡库存，其余占货舱（30 + 6×人数） |
| 委托榜 | 本城委托（规模决定 2–5 条，每 30 日刷新）+ 进行中委托；详情：目标/交付地点/报酬/期限/战斗；接取、交付、放弃（声望 −4） |
| 酒馆 | 3 名候选（按本国血脉池与职业倾向），雇佣费随血统与爵位 |
| 军械库 | 编制列表 + 武器/护具/饰品三槽 + 世界装备库存，实时显示属性差值，职业限制提示 |

**铁匠铺阶数** = 节点基础阶 + 声望≥30 +1 + 声望≥55 +1（上限 4）。

### 5.1 声望解锁（城 / 邦交双层，`World.CITY_UNLOCKS` / `NATION_UNLOCKS`）

| 阶 | 城声望 | 邦交声望 |
|---|---|---|
| 陌生 0 | 基础货品 · 一阶委托 | 敌对/戒备之邦不接外人委托 |
| 认识 10 | 签名兵器 · 二阶委托 · 委托榜 +1 | 该国委托全部开放 · 关税 −3 |
| 友善 30 | 铁匠铺 +1 阶 · 三阶与名誉委托 · 价优 2.5% | 关税全免 · 二阶以上委托开放 |
| 信赖 55 | 铁匠铺再 +1 · 传奇兵器 · 委托榜 +1 · 价优 5% | 全境市集价优 5% · 巡逻放行 |
| 盟誓 80 | 酒馆 +1 爵位候选 · 价优 7.5% · 名誉报酬 +20% | 都城酒馆出现本国最高血脉 |

- 跨阶时弹出里程碑提示并写入城堡日志，委托榜立即按新阶重排。
- 声望来源：首次到访 +2、购买 +1、打造 +2、委托交付、遭遇战胜利 +2、**向求购城供货（每 5 份 +1）**；城声望的一半计入邦交。
- 邦交门槛：敌对之邦（朔影国）一阶委托需邦交 10、二阶起需 30；戒备之邦（清河、灯市）二阶起需 10；任意国三阶普通委托需 10。

### 5.2 委托链

二阶以下普通委托交付后，交付城有 45% 几率递来**续篇**（递送→护送→防守→追缉→清剿…，阶 +1，报酬 +25%，标记 ⛓，跨榜单刷新保留），形成跨城的连续委托线。委托榜可按 全部 / 战斗 / 商旅 筛选，详情列出城声望与邦交门槛。

## 6. 委托

| 种类 | 目标 | 交付 | 战斗 |
|---|---|---|---|
| 递送 deliver | 1–3 跳外的聚落（占 2 货舱） | 目标城 | 否 |
| 护送 escort | 1–3 跳外 | 目标城 | 路遇概率↑，败则失败 |
| 追缉 hunt | 附近聚落，抵达即开战 | 发布城 | 是 |
| 清剿 clear | 指定路段，行经即开战 | 发布城 | 是 |
| 防守 defend | 附近聚落，限期赶到 | 目标城 | 是 |
| 收购 gather | 本城求购货物 ×N | 发布城（消耗货物） | 否 |
| 探查 scout | 1–3 跳外，抵达即同步当地行情 | 发布城 | 否 |

- 报酬 = 模板银 × (1 + 0.3×(跳数−1) + 0.45×(阶−1) + 0.15×(战力层级−1))；二阶起附赠本城特产。
- 阶 2/3 需声望 10/30。同时最多 5 个。超期自动失败（声望 −5）。
- **名誉委托**（73 条手写）：声望≥30 时置顶出现，报酬 ×1.8 + 40，声望 +15，完成解锁本城传奇兵器并写入家族编年。

## 7. 兵器数据

- 223 件：国度制式线 77（每国 7）+ 签名 146（每城 2）。12 种类型（长剑、战刀、长枪、骑枪、战斧、长弓、劲弩、法杖、法器、轻甲、塔盾、护符）。
- 属性按类型轮廓 × 阶数（例：长剑 攻2T 命中5 暴击2；战斧 攻2T+2 命中−10），签名 ×1.45 价格，传奇 ×2.1 + 国度特长加成。
- 签名兵器授予一个既有战技（`TYPE_SKILL` 映射），出战时 `World.grant_gear_skills` 注入。
- 属性通过 `CKCharacter.derived_*` 中的 `World.gear_bonus` 生效；城堡锻造覆盖武器时，世界兵器退回军械库。

## 8. 整合

- **存档**：`GameState.save_game` 写入 `world_v87`（位置、日、声望、市集、委托、军械库、装备槽、遭遇、事件、日志），读档后遭遇战地图重新注册。
- **战役**：`World.mainline_marker()` 把当前主线章节（按卷→国度映射）挂到该国某节点的 ★ 标记，身处该节点可直接进入章节。
- **城堡经济**：粮/铁/药材共享城堡库存；跑图翻月触发城堡月度结算；邦交声望镜像到 GameState 的 ashland / riverland。
- **战斗**：`battle_controller._finish` 检测 `world_encounter` → `World.on_battle_end(win)`，结算后“返回舆图”（失败无“重新挑战”，按败退规则结算）。

## 11. 验收标准（BMGD 风格）

**AC-1 数据完整**
- Given 新游戏，When 载入 World，Then 区域 = 11、节点 ≥ 70、每国 ≥ 4 处聚落、所有节点坐标在板块内、从灰旗堡出发所有节点可达。
- Then 物品 ≥ 200、签名 ≥ 140、名誉委托 ≥ 70、货物 = 17、路遇事件 = 18。

**AC-2 跑图消耗**
- Given 部队在灰旗堡，When 前往白垣，Then 位置 = 白垣，日数增加 = 路线日程，粮减少 = 预览耗粮。
- When 连续行军 31 日，Then 城堡历法至少前进一个月。
- When 粮不足，Then 每日士气 −4，预览提前警告。

**AC-3 国界与海路**
- 跨国路线必经陆桥关隘或海路；过关扣该国关税，海路扣船资；预览列出经过的国界。

**AC-4 铁匠铺**
- Given 白垣声望 12，Then 签名兵器可买、传奇显示锁定原因（需名誉委托）。
- When 购买并装备，Then 攻击、命中按物品属性上升；出战时获得签名战技。
- When 自带材料打造，Then 只付工钱并消耗材料。

**AC-5 市集**
- 买入使存货减少、下一件更贵；产地价低于求购地价；粮/铁/药材入城堡库存，其余受货舱限制。

**AC-6 委托**
- 委托只能在发布城接取；锁定委托显示原因；到达目标/战胜后状态变“可交付”；只能在规定城市交付；交付获得银、声望、经验（与特产）。
- 名誉委托完成后，该城传奇兵器在声望达标时可购买。

**AC-7 遭遇战**
- 委托/路遇触发战斗时，生成地图使用节点生物群系底图、该国敌人模板；真实战斗场景载入该地图；胜利 → 目标达成并继续行程；失败 → 退回出发地并结算惩罚。

**AC-8 存档**
- 存档 → 重置 → 读档后：位置、日数、城声望、名誉进度、军械库、货舱、已装备兵器与属性、委托日志全部还原。

**AC-9 UI**
- 舆图节点数 = 该国节点数；点击相邻节点可通过 UI 完成行军并移动旗标；世界视图显示 11 区域。
- 城镇六页签都能渲染；通过 UI 按钮完成铁匠铺购买、市集买入、接取委托。
- 所有可交互控件具备五态，禁用原因可见。

**AC-10 美术一致性**
- 所有入库的城市/铁匠/图标图均通过 style gate；审阅图存档；未入库者使用回退，不出现羊皮纸/中世纪暖金风格。

**AC-11 声望与委托深度**
- 跨阶触发里程碑并扩充委托榜；敌对之邦在邦交不足时锁定委托并说明原因；友善邦交免关税；委托链续篇出现在交付城榜首；盟誓城酒馆出现爵位候选。

以上 AC-1 … AC-9、AC-11 由 `project/tests/atlas_e2e.gd` 自动验证，并已接入 `scripts/run_ci.sh`；AC-10 由入库脚本把关。
