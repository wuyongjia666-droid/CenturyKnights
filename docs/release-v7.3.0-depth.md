# v7.3.0-depth · 系统深度第四轮（仍停加卷）+ 美术一等公民

**定位**：继续只做既有系统极致打磨——**不加新剧情卷**。本轮起美术与系统同级交付：地图地块、交战锁定特效、属地图标、兵种板绘、堡顶 UI 条、BGM 加厚均写入本说明。

## 玩法 / 系统

### ZoC「交战反击锁定」
- 攻/受击双方进入 **交战锁定**（约 1 回合）：棋子外圈锁定环 + 「锁定」飘字。
- 锁定中 **脱离代价 +2 移**（高于普通交战 +1）。
- 锁定单位反击时命中 +10，日志显示「交战锁定反击 / 锁反」。
- 单位信息面板：`〔交战锁定·脱离+2移·反击优先〕`。

### 属地庄园加深（仍单堡多属地）
- **庄头委任 / 撤任**：花名册存活成员，一人一属地。
- 庄头：**月结产出 +1 档**，并显著降低劫掠风险。
- 无庄头：士气偏低时可能 **劫掠**（本月无收成 + 士气惩罚），写入堡志/族谱事件。
- 面板：**属地图标**、产出预览、庄头状态、升级。
- 堡志新增/挂钩：**庄头遍野**（至少 2 处庄头）、**家训周岁**（立训满 12 月）、精锻等。

### 堡志 · 家训 · 联姻月结
- 立家训后每月累计 `doctrine_months`；严教/仁恤/商本月结生效；满 12 月「家训周岁」强化。
- 联姻月结：配偶存活 → 士气；在花名册再 +银。
- 属地收成并入沙漏月结流程。
