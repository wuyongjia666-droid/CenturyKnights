# 美术风格圣经 · 百年骑士

2026 当代奇幻。磨砂玻璃、墨蓝虚空、霜青焦点。敌我用形状加薄荷 / 珊瑚，不靠暖色金属。

## 色板

取自 `docs/art/style-lock-v89.json` 与 `UIKit` 常量。

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 墨蓝虚空 | `#07080C` | 全屏底 |
| 虚空辉光 | `#10141C` | 网格与远处 |
| 面板 | `#161B24` | 磨砂玻璃底 |
| 抬升面板 | `#1C2330` | 卡片、弹层 |
| 正文 | `#F4F7FB` | 标题与正文 |
| 次级文字 | `#9AA6B8` | 说明 |
| 霜青 | `#6ED4FF` | 主按钮、焦点、选中 |
| 霜青悬停 | `#9BE4FF` | 悬停 |
| 霜青按下 | `#3AADDF` | 按下 |
| 薄荷 | `#5EE0B5` | 友军、确认、治愈 |
| 珊瑚 | `#FF7A70` | 敌军、拒绝、危险 |
| 火花 | `#FF8A3D` | 只用于短暂火花，不铺界面 |

高对比模式把底收成纯黑、字收成纯白，霜青提到 `#9BE4FF`。色觉模式另有蓝 / 黄信号色，见设置页，不替代这张默认色板。

## 材料

- 面板是半透明石板玻璃：1px 冷白描边，圆角 8–16，软阴影向下。
- 金属只做磨砂冷铬和高光细线，反光偏霜青。
- 布料是哑光工业织物。立绘轮廓是 `#0A0E14` 的细线。
- 禁止：纸纹、暖色金属镶边、烛火、日落调色、哥特石雕、纹章盾牌当界面框。

## 组件

都在 `UIKit`，状态走 `UIFX.wire_button`（普通、悬停、按下、焦点、禁用）。

| 组件 | 入口 | 要点 |
| --- | --- | --- |
| Button | `make_button` / `make_accent_button` / `ghost_button` / `cta_button` | 主按钮霜青底、墨字；次按钮透明底。高度至少 44。按下缩放并提亮。 |
| Chip | `tag_chip` / `stat_chip` / `res_chip` | 小胶囊。实心只用于状态，空心用于分类。 |
| Card | `stat_box` / `portrait_plate` | 抬升玻璃。一张卡一件事，标题 18，说明 12。 |
| Panel | `make_panel` / `panel_at` / `plate_style` | 大面玻璃。旧的大写颜色别名只指向正文色，新代码用 `TEXT` 或 `plate_style`。 |
| Tab | `tab_bar` | 横排分段。选中项霜青字和底边，未选中次级文字。 |
| ListRow | `list_row` / `kv_row` | 左标题、右元数据，行高至少 44。 |
| Dialog | `dialog_panel` | 居中抬升玻璃，标题、正文、一排按钮。不用暖色镶边。 |

## 文字

- 中文：Noto Sans CJK SC 子集。标题 28–32，章节 18–22，正文 15，说明 12–13。
- 数字与眉题：JetBrains Mono。
- 眉题用霜青大写英文，正文用 `#F4F7FB`。

## 敌我

默认薄荷圆是友军，珊瑚三角是敌军。色觉模式改色板，形状不变。危险区用珊瑚低透明度铺格。

## 动效

转场不超过 0.25 秒。减动效时不超过 0.08 秒。触感只在设置打开时，对移动端关键确认调用。
