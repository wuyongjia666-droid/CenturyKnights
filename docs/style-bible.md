# 美术风格圣经 · CenturyKnights（灰烬旗）

## 调色
- 底：冷灰蓝 `#1a1f28` / `#10141a`
- 灰烬金 `#c9a227`（主强调、团长环、胜势）
- 旗红 `#8b2e2e`（危险、敌军）
- 羊皮纸字 `#ede8db` / 暗字 `#9e9a8c`
- 石边框 `#474b5c`

## 角色立绘（程序生成，原创）
- 头身简洁色块：发色/瞳色/眉形/疤来自 `appearance.json` 等位基因
- 职业甲色区分：猎手绿、秘术紫、重甲灰、骑手枪饰
- 队色披风条：我军用纹章色，敌军暗红
- 团长外环金圈

## 战棋棋子
- 48px 级 token：头+躯干+武器剪影（剑/弓/杖）
- HP 条、短名签、选中脉冲环、移动蓝格/攻击红格

## 战旗
- 燕尾旗 + 中央盾徽焰纹 + 姓氏底条
- 颜色绑定 `GameState.crest_color`，立姓界面即时预览

## UI
- Theme + StyleBoxFlat：圆角卡片、金边、阴影
- 枢纽导航按钮双行（标题+副文）
- 禁止：灰泥糊成一团；禁止对标游戏截图/素材
