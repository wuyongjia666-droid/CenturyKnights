# v9.1.0-art · 多征血脉、霜庭与百年

自 `v8.8.0-art` 之后合入 main 的玩法与界面，基线 `e755b71`。风格锁未改，没有新的农场贴图入库。

## 本版

- **多征血脉**：十国各有王室、高爵、庶支。原有十枚冠征仍决定继承、战技与身价；后接的禀性组（发、瞳、骨、肤、仪态、仪仗，以及少见的纯血显征）按该国血律遗传。血是身上带着的，冠是亮出来的。
- **霜庭界面**：血脉图鉴、人物卷宗、验血、婚仪、邸报、爵位。各国用自己的徽记，条文不再叠在同一行上。
- **百年推演与平衡**：种子 91 的脚本化佣兵团按真实规则跑满约五代。封地月银、丰收、粮仓腐耗和委托底价收在 `docs/design/balance-v91.md` 的目标带里：银粮不漏也不爆，爵位过得了子爵，十国王室还在。
- **年龄段立绘管线**：基因组半身像按婴儿、少年、青年、中年、老年写进同一套提示词（脸的比例、发、肤、站姿、衣着）。农场照清单出图，入库按 `unit_id` 对回。亲属相像靠共用描述，不靠同一张图。纸娃娃叠层已退出这条管线。
- **Android 触控**：点按、长按、单指平移、双指缩放；安全区覆盖 16:9 与 20:9。桌面鼠标路径不变。调试包仍用 `scripts/build_android.sh`。
- **敌方主题**：各势力复用已入库的 GLB 套装（近战、远程、精锐、轻装）。配色留在霜色风格锁内，余烬只作点缀。
- **灯籍、婚仪、王室 NPC、爵位**：灯席议价、婚仪、十国 NPC 王室的周转，以及功勋爵梯（勋士、男爵、子爵、伯爵、侯爵）。

## 风格锁

霜色 #6ED4FF · 薄荷 #5EE0B5 · 珊瑚 #FF7A70 · 余烬 #FF8A3D。当代奇幻，不是中世纪金纹。门禁：`tools/art/style_check_v87.py`。
