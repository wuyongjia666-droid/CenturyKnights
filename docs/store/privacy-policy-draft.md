# 隐私政策草稿（上架前静态页）

> **草稿**：上架前挂到可公网访问的静态 URL；本仓库只保留文案。  
> 原则：单机优先；**不收集**非必要个人数据；**不出售**数据；崩溃通道若开启须明示。  
> 业主名 / 联系邮箱上架前替换；勿在 git 写私人地址。

## 适用范围

本政策适用于《百年骑士》（CenturyKnights）在 Android / Windows 上的游戏客户端（下称「本游戏」）。  
本游戏以单机玩法为主。若后续增加在线账号或云存档，将更新本政策并在商店页提示。

## 我们收集什么

| 类别 | 今日意图 |
|---|---|
| 账户信息（姓名、邮箱、手机） | **不收集**（无强制账号） |
| 精确位置 | **不收集** |
| 通讯录 / 相册 / 文件 | **不收集**（除系统存档目录由系统 API 管理） |
| 设备标识符用于广告 | **不使用** |
| 支付信息 | 由商店平台处理；开发者不经手卡号 |
| 崩溃 / 性能日志（可选） | 若开启：仅技术诊断（机型、OS 版本、崩溃堆栈）；**不**含可识别姓名 |

默认：**不收集**。若某版本开启崩溃上报，须在本页「崩溃」一节写明开关位置与关闭方式，并在 Play 数据安全表据实勾选。

## 我们如何使用

- 提供单机游戏功能与本地存档  
- （可选）修复崩溃、改进性能  
- **不**用于广告画像  
- **不出售**、不出租、不与数据经纪人共享个人数据  

## 权限（Android，按实际上架包勾选）

| 权限 | 是否需要 | 说明 |
|---|---|---|
| 网络 | 可选 | 仅当崩溃上报或未来在线功能开启 |
| 存储 / 媒体 | 按系统版本 | 存档与截图；遵循分区存储 |
| 通知 | 可选 | 今日无强依赖 |
| 广告 ID | **不使用** | |

Windows 桌面版不额外索取浏览器式权限；存档位于用户目录。

## 儿童

本游戏目标分级 12+（见 `age-rating-draft.md`）。不面向 13 岁以下儿童收集个人信息。若监护人认为有误收集，按「联系」节请求删除（单机卸装即可清除本地数据）。

## 第三方

- Google Play / Microsoft Store：按其平台隐私政策处理购买与分发  
- Godot / 引擎与开源组件：见工程许可证；不因此自动收集个人数据  
- 若未来接入分析 SDK：必须列名、列用途，并允许关闭  

## 数据保留与删除

- 本地存档：用户卸装或清除应用数据即删除  
- 崩溃日志（若有）：仅保留排障所需最短周期，到期删除  
- 无云端账户则无「下载我的数据」包；若将来有云，另开刀补权利说明  

## 不收集 / 不出售 / 崩溃（门禁关键词区）

我们**不收集**非必要个人信息。我们**不出售**用户数据。  
若启用**崩溃**上报，仅用于稳定性，不用广告，可在设置中关闭（上架版须实现该开关后再勾数据安全表）。
