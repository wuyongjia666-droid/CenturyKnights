# 年龄分级预填草稿（IARC / 商店问卷）

> **草稿**：对应 Google Play IARC 问卷与 Microsoft 年龄分级意向。  
> 目标：**12+**（青少年及以上）。战棋抽象冲突，无内购赌博，无写实血腥。

## 目标结论

| 平台 | 意向 |
|---|---|
| Google Play | PEGI / IARC 对标约 12；国内商店若另有规则另开刀 |
| Microsoft Store | 适合青少年及以上（无成人向、无赌博） |
| 自述 | 12+ |

## 问卷预填意图（暴力）

| 问题意向 | 答法 |
|---|---|
| 是否有暴力 | 有：战棋/战术战斗，抽象或风格化打击 |
| 是否有写实血腥 / 肢解 | **无** |
| 是否有恐怖惊吓 | **无**（可有紧张战况，非恐怖类型） |
| 是否有性内容 / 裸露 | **无**（联姻为叙事/系统，不色情描写） |
| 是否有脏话 | 无或极少；不作为卖点 |
| 是否有赌博 / 模拟赌博 | **无**；**无内购**抽卡、开箱、筹码 |
| 是否有网购 / 未经监护人的消费诱导 | 买断制；商店内购栏为 **无** |
| 是否有用户间聊天 | 今日无公开聊天 |
| 是否有位置共享 | **无** |

## 与商店文案一致的三句话（门禁关键词）

1. 目标分级 **12+**。  
2. **无内购**；买断制，不靠抽卡。  
3. 暴力为战棋抽象冲突，非写实血腥。
