> 承接季#1–#9「无/偏/功粮/训行/栏椅/栏场/栏仪/栏祠/栏验」：本季换成「栏与印」——名册城印对得上盖印诚实。

## 1. 一句话

旗册把城印写成栏（旗），本城之事与声望与盖印写成未结（灯）；本季不改栏公式、不改职印规则，只逼人**栏与印并排**，并让盖印进月回响。

## 2. 主题

| 主题 | 本季怎么落地 | 与前季回响 |
|---|---|---|
| 旗与灯 | 名册「城印已盖」vs 本城之事/声望/印未盖 | … → 栏/验 → 本季「栏/印」 |
| 纸比嘴硬 | 名册末页、并排纸、属地墙牌、侧室回执条 | … → 血验并排 → 职印并排 |
| 并排不是和稀泥 | 左栏右印；拒只留城印名 | 栏也不能洗职印 |
| 半截话 | 议会只爱听「城印已盖」；门廊先看牌 | 「城印已盖」要配办事与声望 |
| 代价 | 空挂丢脸；撕并排纸；档案红脸 | 对照与闲话 |

## 3.1 对白口吻（游戏内）

- 大白话；一句一事；单行 ≤60 汉字，最好 ≤30。
- 机制点名：职印、盖印、本城之事、声望、沙漏两行、属地墙牌、六门印——直接说。
- 不说「系统」「month_echo」——说「沙漏多一行职印」「属地那块牌」「谁还没办事」。
- 对照物：笔、名册、牌、末页、花生壳圈、印泥、印灯。禁精灵耳/鎏金等 anti_trope。
