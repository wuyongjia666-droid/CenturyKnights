# 内容季 #4 · 圣经 ·《家训上的灯》

> 原著：[`NOVEL.md`](NOVEL.md)（≥1.2 万汉字，对标《回执上的灯》/《婚约上的灯》/《榜上的收成》）。
> 可玩稿：`project/data/story/chapters/cs04_01.json`（见 [`PLAYABLE.md`](PLAYABLE.md)）。
> 选题：[`TOPIC.md`](TOPIC.md)。系统加深：家训 → 月回响 `doctrine` 可感。
> 承接季#1「无进谱」、季#2「偏并排」、季#3「功与粮」：本季把冲突换成「训与行并排」——旗角绣词对得上沙漏家训行。

## 1. 一句话

旗册把家训绣成名（旗），月结把执行写成数（灯）；本季不改绣、不改公式，只逼人**训与行并排**。

## 2. 主题

| 主题 | 本季怎么落地 | 与前季回响 |
|---|---|---|
| 旗与灯 | 旗角绣词 vs 沙漏 `month_echo.doctrine`；墙上牌抄月结 | 岁课「无」→ 婚盏「偏」→ 功/粮 → 本季「训/行」 |
| 纸比嘴硬 | 绣面、旗册末页、并排纸、属地墙牌 | 挂板 → 婚约匣 → 朝报钉墙 → 家训并排 |
| 并排不是和稀泥 | 左名右数；拒只留训条 | 「无」「偏」「功/粮」后续：绣词也不能洗执行 |
| 半截话 | 议会只爱听念；门廊先看牌 | 酒馆半截 → 本季「教得出来」要配月 |
| 代价 | +0 挂出来丢脸；撕并排纸；成熟前不装完美 | 代价仍是对照与闲话，不是改制度 |

## 3.1 对白口吻（游戏内）

- 大白话；一句一事；单行 ≤60 汉字，最好 ≤30。
- 机制点名：家训、绣词、月结、沙漏家训行、属地墙牌——直接说。
- 不说「系统」「month_echo」——说「沙漏多一行家训」「属地那块牌」「本月粮动了没有」。
- 对照物：针、绣面、牌、末页、花生壳圈、油布。禁精灵耳/鎏金等 anti_trope。
