## 1. 一句话

旗册把祖祠写成栏（旗），碑与点灯写成未结（灯）；本季不改栏公式、不改祖祠规则，只逼人**栏与祠并排**。

## 2. 主题

| 主题 | 本季怎么落地 | 与前季回响 |
|---|---|---|
| 旗与灯 | 名册碑名 vs 祖祠对碑/点灯进度 | … → 栏/仪 → 本季「栏/祠」 |
| 纸比嘴硬 | 名册末页、并排纸、属地墙牌、侧室回执条 | … → 仪典并排 → 祖祠并排 |
| 并排不是和稀泥 | 左栏右祠；拒只留碑名 | 栏也不能洗祖祠 |
| 半截话 | 议会只爱听念；门廊先看牌 | 「碑写全了」要配点灯 |
| 代价 | 空挂丢脸；撕并排纸 | 对照与闲话 |

## 3.1 对白口吻（游戏内）

- 大白话；一句一事；单行 ≤60 汉字，最好 ≤30。
- 机制点名：祖祠、碑、点灯、沙漏两行、属地墙牌——直接说。
- 不说「系统」「month_echo」——说「沙漏多一行祖祠」「属地那块牌」「谁还没对碑」。
- 对照物：笔、名册、牌、末页、花生壳圈、香灰。禁精灵耳/鎏金等 anti_trope。
