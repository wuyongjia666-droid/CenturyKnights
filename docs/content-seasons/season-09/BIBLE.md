## 1. 一句话

旗册把血验写成栏（旗），验条与点验写成未结（灯）；本季不改栏公式、不改血验规则，只逼人**栏与验并排**。

## 2. 主题

| 主题 | 本季怎么落地 | 与前季回响 |
|---|---|---|
| 旗与灯 | 名册血名 vs 血验对条/点验进度 | … → 栏/祠 → 本季「栏/验」 |
| 纸比嘴硬 | 名册末页、并排纸、属地墙牌、侧室回执条 | … → 祖祠并排 → 血验并排 |
| 并排不是和稀泥 | 左栏右验；拒只留血名 | 栏也不能洗血验 |
| 半截话 | 议会只爱听念；门廊先看牌 | 「验条写全了」要配点验 |
| 代价 | 空挂丢脸；撕并排纸 | 对照与闲话 |

## 3.1 对白口吻（游戏内）

- 大白话；一句一事；单行 ≤60 汉字，最好 ≤30。
- 机制点名：血验、验条、点验、沙漏两行、属地墙牌——直接说。
- 不说「系统」「month_echo」——说「沙漏多一行血验」「属地那块牌」「谁还没对条」。
- 对照物：笔、名册、牌、末页、花生壳圈、验灯。禁精灵耳/鎏金等 anti_trope。
