# 内容季 #3 · 圣经

> 对齐 `NOVEL.md`《榜上的收成》。

## 一句话 / 主题

朝报把委托军功写成榜（旗），属地月结把收成摊成数（灯）；本季不改榜、不改田，只逼人**功与粮并排**。

## 动机

- **团长**：要榜上的功撑住名册，也要田里的数撑住脸。
- **属地管家**：要月结数字对得上粮仓；炭笔点三下是警告。
- **朝报书记**：只抄军功，不抄收成；「篇幅」是借口。
- **酒馆瘦子**：爱裁亏留功；被按住剪刀时，才肯让两行同钉。

## 节拍

1. 委托交付，朝报记功（旗）
2. 属地月结出来（灯）
3. 沙漏两行并排
4. 酒馆问：功是吃的，还是看的？
5. 团长选「功与粮并排」；木条靠墙；议会「存档不刊」

## 口吻

短句。数字用「少了三成」「多记了一笔」，不说变量名。泥、菜、脚印是对照物。

## 可玩压点

- 选择：改榜 / 改田 / 并排对照 → 收束走并排。
- 系统落点：委托/属地 → `house_mods.month_echo` 对照可感。
