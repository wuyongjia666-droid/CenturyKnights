# 内容季 #3 · 圣经 ·《榜上的收成》

> 对齐 `NOVEL.md`。可玩章 `cs03_01`。系统落点：委托/属地月回响对照。

## 一句话 / 主题

朝报把委托军功写成榜（旗），属地月结把收成摊成数（灯）；本季不改榜、不改田，只逼人**功与粮并排**。

## 旗 / 灯

| | 旗 | 灯 |
|---|---|---|
| 物 | 朝报军功栏、摘要印、名册 | 属地月结、沙漏下行、锈穗夹页 |
| 诱惑 | 只留交付、倍功、重大门槛 | 用收成洗逾期、空窗假填 |
| 代价 | 借功压粮价；工抽走穗倒 | 藏下行＝对照死；脸不红 |

## 动机

- **团长**：要榜上的功撑住名册，也要田里的数撑住脸；宁可两行都深，不让一行骗人。
- **老管事**：月结对得上粮仓；炭笔点三下是警告；柜子两把钥匙，沙漏证明月还在走。
- **书记官**：只抄军功；「篇幅」「重大」是挡板；摸过下行之后，嗓子会轻一点。
- **掌柜**：白纸黄纸并排钉；剪刀收走；证人栏记谁摸过拓片。
- **晚担 / 灯影**：一人盐车一人留田；不全就不全，并排写。
- **青禾**：摸过亏的人，才配夸功；孩子会说「少」「并」。
- **敌宅**：借功谈判；送带泥的菜＝认过下行；账房抄手会顿笔。

## 节拍（中篇 → 可玩）

1. 委托交付，朝报记功（旗）→ 拍 `merit`
2. 属地月结对不上（灯）→ 拍 `estate`
3. 沙漏两行并排刻凹槽 → 拍 `hourglass`
4. 陆桥念拓片；粮价问下行 → 拍 `bridge`
5. 酒馆钉墙；选并排或先只留功 → 拍 `tavern` / `ledger`

## 口吻

短句。数字用「少了三成」「多记了一笔」，不说变量名。泥、菜、锈穗、凹槽、拓片是对照物。禁精灵耳/鎏金/羊皮纸等 anti_trope。

## 可玩压点

- 选择：**功与粮并排**（`cs03_kept_parallel`）/ **先只留功**（`cs03_merit_only`）→ 收束都进 `ledger`；并排是原著主线。
- 系统落点：委托交付/逾期 → `month_echo.commission`；属地月结 → `month_echo.estates`；对照可感。
- 议会「存档不刊」不是胜利结局，是缝；缝比门宽。
