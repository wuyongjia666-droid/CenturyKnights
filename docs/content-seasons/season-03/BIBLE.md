# 内容季 #3 · 圣经 ·《榜上的收成》

> 原著：[`NOVEL.md`](NOVEL.md)（≥1.2 万汉字，对标《婚约上的灯》/《回执上的灯》）。
> 可玩稿：`project/data/story/chapters/cs03_01.json`（见 [`PLAYABLE.md`](PLAYABLE.md)）。
> 选题：[`TOPIC.md`](TOPIC.md)。系统加深：委托/属地 → 月回响 `commission` / `estates` 对照可感。
> 承接季#1「无进谱」、季#2「偏并排」：本季把冲突换成「功与粮并排」——榜上的交付对得上田里的数。

## 1. 一句话

朝报把委托军功写成榜（旗），属地月结把收成摊成数（灯）；本季不改榜、不改田，只逼人**功与粮并排**。

## 2. 主题

| 主题 | 本季怎么落地 | 与前季回响 |
|---|---|---|
| 旗与灯 | 朝报军功栏 vs 属地月结下行；沙漏两行凹槽 | 岁课「无」→ 婚盏「偏」→ 本季「功/粮」 |
| 纸比嘴硬 | 摘要印、拓片、钉墙两纸、证人栏 | 挂板七天 → 婚约匣 → 朝报贩子剪刀 |
| 并排不是和稀泥 | 上行交付、下行收成；拒单行漂亮结论 | 「无进谱」「偏并排」的后续：功也不能洗粮 |
| 半截话 | 陆桥问粮最快；整句在月回响条上长 | 酒馆半截 → 本季铃第二次、钉第三张 |
| 代价 | 借功压粮价、工抽走穗倒、议会「重大」门槛 | 代价仍是对照与闲话，不是改制度 |

## 3.1 对白口吻（游戏内）

- 大白话；一句一事；单行 ≤60 汉字，最好 ≤30。
- 机制点名：朝报、军功栏、属地月结、沙漏两行、委托逾期——直接说。
- 不说「系统」「month_echo」——说「属地那张条」「沙漏多一行凹槽」「委托那笔逾期」。
- 对照物：泥、菜、锈穗、拓片、凹槽、剪刀、木条。禁精灵耳/鎏金/羊皮纸等 anti_trope。

## 7. 可玩压点

- 选择：**功与粮并排**（`cs03_kept_parallel`）/ **先只留功**（`cs03_merit_only`）→ 收束都进 `ledger`；并排是原著主线。
- 系统落点：委托交付/逾期 → `month_echo.commission`；属地月结 → `month_echo.estates`；对照可感。
- 议会「存档不刊」「重大」门槛不是胜利结局，是缝；缝比门宽。

## 8. 不做（本季）

- 不改朝报制度本身（不强制刊下行）
- 不把敌宅写成改宗盟友
- 不新开战棋关卡；不改联姻/岁课主线
- 不让「只留功」成为无代价捷径——条上仍留下行痕迹
