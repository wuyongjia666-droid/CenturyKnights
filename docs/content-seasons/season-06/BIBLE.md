## 1. 一句话

旗册把嗣位写成栏（旗），月结与校场把争锋写成未结（灯）；本季不改栏公式、不改校场规则，只逼人**栏与场并排**。

## 2. 主题

| 主题 | 本季怎么落地 | 与前季回响 |
|---|---|---|
| 旗与灯 | 名册可比试 vs 沙圈/疤/站位进度；墙上牌抄两行 | 岁课「无」→ 婚盏「偏」→ 功/粮 → 训/行 → 栏/椅 → 本季「栏/场」 |
| 纸比嘴硬 | 名册末页、并排纸、属地墙牌、侧室回执条 | 挂板 → 婚约匣 → 朝报钉墙 → 家训并排 → 空椅并排 → 校场并排 |
| 并排不是和稀泥 | 左栏右场；拒只留胜者名 | 「无」「偏」「功/粮」「训/行」「栏/椅」后续：栏也不能洗校场 |
| 半截话 | 议会只爱听念；门廊先看牌 | 酒馆半截 → 本季「打得出来」要配疤 |
| 代价 | 空挂出来丢脸；撕并排纸；成熟前不装完美 | 代价仍是对照与闲话，不是改制度 |

## 3.1 对白口吻（游戏内）

- 大白话；一句一事；单行 ≤60 汉字，最好 ≤30。
- 机制点名：嗣位校场、沙圈、疤、沙漏两行、属地墙牌——直接说。
- 不说「系统」「month_echo」——说「沙漏多一行校场」「属地那块牌」「谁还站得住」。
- 对照物：笔、名册、牌、末页、花生壳圈、护腕。禁精灵耳/鎏金等 anti_trope。
