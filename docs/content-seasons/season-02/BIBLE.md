# 内容季 #2 · 圣经

> 对齐 `NOVEL.md`《婚约上的灯》。可玩章口吻从此表出。

## 一句话 / 主题

婚约把新姓钉进名册（旗），验盏回执把「脉偏」钉进属地与沙漏（灯）；本季不改名册、不改回执，只学会**两行并排念完**。

## 动机

- **团长侧**：要一张议会认的婚约，好让嗣位庭有人可立；更要一套念法，让偏灯也能进谱而不撒谎。
- **配偶侧**：要知道孩子脸上的灯会不会把婚约上的姓撕开；要酒馆挂谣时仍有人敢留痕。
- **验盏人**：只念回执，不站队；附注写「三者同时真」，交给档案馆存。
- **管家**：把婚仪条与诞育条刻成两根木条，逼人每月并排念。

## 节拍

1. 婚约落印（旗）
2. 月回响里诞育条目出现（系统可感）
3. 验盏回执与名册对不上（灯）
4. 酒馆先挂摘抄、议会后问
5. 团长选「并排两行」：改读法，不改纸
6. 敌宅送泥菜试探；册脊写「婚盏」

## 口吻

对白短、土、不解释世界观。不说「系统」「月回响」——说「属地那张条」「沙漏里多出来的一行」「并排念完」。

## 可玩压点

- 选择：把偏写进谱 / 先压下 → 都进收束，但旁白与月回响附注不同。
- 系统落点：诞育/联姻 → `house_mods.month_echo` 属地/沙漏可回读。
