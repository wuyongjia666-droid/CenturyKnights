# 内容季 #2 · 圣经 ·《婚约上的灯》

> 原著：[`NOVEL.md`](NOVEL.md)（≥1.2 万汉字，对标《那个字》/《回执上的灯》）。
> 可玩稿：`project/data/story/chapters/cs02_01.json`（见 [`PLAYABLE.md`](PLAYABLE.md)）。
> 选题：[`TOPIC.md`](TOPIC.md)。系统加深：诞育/联姻 → 月回响属地/沙漏可感。
> 承接季#1「无进谱」：本季不推翻「空可以是答案」，把冲突换成「偏也可以并排留下」。

## 1. 一句话

婚约把新姓钉进名册（旗），验盏回执把「脉偏」钉进属地与沙漏（灯）；本季不改名册、不改回执，只学会**两行并排念完**。

## 2. 主题

| 主题 | 本季怎么落地 | 与季#1 回响 |
|---|---|---|
| 旗与灯 | 婚约姓栏 vs 回执脉偏；嗣位空椅要两行 | 岁课「无」→ 婚盏「偏」；都是验过的真 |
| 纸比嘴硬 | 落印、月回响条、朝报「待对」、庭附注 | 挂板七天 → 酒馆摘抄与指甲痕 |
| 并排不是和稀泥 | 上行婚仪、下行诞育；摘要拒单行漂亮结论 | 「无进谱」的后续：偏也进条 |
| 半截话 | 酒馆最快；整句在条上长 | 景伯七天影子：这次灰旗自己留痕 |
| 代价 | 敌宅买灯、议会沉默、联姻市场笑柄 | 代价仍是闲话与核对，不是银 |

## 3.1 对白口吻（游戏内）

- 大白话；一句一事；单行 ≤60 汉字，最好 ≤30。
- 机制点名：婚约、回执、属地条、沙漏两行、并排——直接说。
- 不说「系统」「month_echo」——说「属地那张条」「沙漏多一行」。
