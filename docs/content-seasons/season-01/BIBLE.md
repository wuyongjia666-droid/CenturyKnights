# 内容季 #1 · 圣经 ·《回执上的灯》

> 原著：[`NOVEL.md`](NOVEL.md)（约 1.2 万汉字，对标序章《那个字》体量与密度）。
> 可玩稿：`project/data/story/chapters/cs01_01.json`（见 [`PLAYABLE.md`](PLAYABLE.md)）。
> 选题：[`TOPIC.md`](TOPIC.md)。系统加深：岁课回执 → 族谱年迹（Y1-B 已落地）。
> 本文只往上加「第一张岁课」的人与选择，不推翻序章圣经与主线圣经已定事实。

## 1. 一句话

陆桥上第一次有人当众问：这面灰旗到底是**声称**还是**脸上的灯**——孩子岁课的回执成了族谱里第一张推不开的纸；征兆栏写「无」，无进谱，旗仍在。

## 2. 主题

| 主题 | 本季怎么落地 | 与序章回响 |
|---|---|---|
| 旗与灯 | 议会要纸上的征兆；联姻宅要「习灯」文书；灰旗选择把空格写成「无」而不是借颜料 | 青禾「不要借来的灯」从口号变成回执上的字 |
| 纸比嘴硬 | 岁吏送纸、听回验盏、酒馆挂板七天、年迹入谱 | 那个字从旗面落到族谱格子 |
| 空不是罪 | 「无」不是失败，是验过的事实；事实进谱才不被酒馆随便涂 | 稳婆「肺是孩子自己的」的后续 |
| 跟随仍分三种 | 晚担跟人、灯影跟路、旁人跟谈资；谈资在七天后散，跟人跟路的还在 | 序章三种理由在岁课后被再试一次 |
| 代价由谁付 | 敌宅帖、槐里「河图见习」、议会沉默；代价是闲话与联姻压力，不是银 | 景伯三十年前七天的影子：这次灰旗自己写纸 |

## 3.1 对白口吻（游戏内）

- 大白话；一句一事；单行 ≤60 汉字，最好 ≤30。
- 机制点名：岁课回执、验盏、挂板七天、年迹入谱——直接说，不绕意象。
- 声口靠态度：晚担实在，灯影干脆，青禾直接，听回公事，岁吏像收据。
- 原著意象（白圆、空格子、拓印）游戏里点到为止，不靠它推选择。
