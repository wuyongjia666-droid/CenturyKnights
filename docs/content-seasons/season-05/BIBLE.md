# 内容季 #5 · 圣经 ·《空椅上的灯》

> 原著：[`NOVEL.md`](NOVEL.md)（≥1.2 万汉字，对标前四季中篇）。
> 可玩稿：`project/data/story/chapters/cs05_01.json`（见 [`PLAYABLE.md`](PLAYABLE.md)）。
> 选题：[`TOPIC.md`](TOPIC.md)。系统加深：联姻→继承→嗣位链可感（`marriage_heir_chain`）。
> 承接季#1「无进谱」、季#2「偏并排」、季#3「功与粮」、季#4「训与行」：本季把冲突换成「栏与椅并排」——名册待定对得上空椅诚实。

## 1. 一句话

旗册把嗣位写成栏（旗），月结与空椅把链写成空（灯）；本季不改栏公式、不改继承规则，只逼人**栏与椅并排**。

## 2. 主题

| 主题 | 本季怎么落地 | 与前季回响 |
|---|---|---|
| 旗与灯 | 名册待定 vs 空椅/联姻链进度；墙上牌抄两行 | 岁课「无」→ 婚盏「偏」→ 功/粮 → 训/行 → 本季「栏/椅」 |
| 纸比嘴硬 | 名册末页、并排纸、属地墙牌、侧室回执条 | 挂板 → 婚约匣 → 朝报钉墙 → 家训并排 → 空椅并排 |
| 并排不是和稀泥 | 左栏右空；拒只留栏名 | 「无」「偏」「功/粮」「训/行」后续：栏也不能洗空椅 |
| 半截话 | 议会只爱听念；门廊先看牌 | 酒馆半截 → 本季「教得出来」要配链 |
| 代价 | 空挂出来丢脸；撕并排纸；成熟前不装完美 | 代价仍是对照与闲话，不是改制度 |

## 3.1 对白口吻（游戏内）

- 大白话；一句一事；单行 ≤60 汉字，最好 ≤30。
- 机制点名：嗣位栏、空椅、联姻链、沙漏两行、属地墙牌——直接说。
- 不说「系统」「month_echo」——说「沙漏多一行空椅」「属地那块牌」「链走到哪一格」。
- 对照物：笔、名册、牌、末页、花生壳圈、油布。禁精灵耳/鎏金等 anti_trope。
