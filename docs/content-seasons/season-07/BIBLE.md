## 1. 一句话

旗册把认宗写成栏（旗），仪典把选路写成未结（灯）；本季不改栏公式、不改仪典规则，只逼人**栏与仪并排**。

## 2. 主题

| 主题 | 本季怎么落地 | 与前季回响 |
|---|---|---|
| 旗与灯 | 名册路名 vs 仪典选路/盖印进度；墙上牌抄两行 | 岁课「无」→ … → 栏/场 → 本季「栏/仪」 |
| 纸比嘴硬 | 名册末页、并排纸、属地墙牌、侧室回执条 | 挂板 → … → 校场并排 → 仪典并排 |
| 并排不是和稀泥 | 左栏右仪；拒只留路名 | 栏也不能洗仪典 |
| 半截话 | 议会只爱听念；门廊先看牌 | 「路选好了」要配盖印 |
| 代价 | 空挂出来丢脸；撕并排纸；成熟前不装完美 | 代价仍是对照与闲话 |

## 3.1 对白口吻（游戏内）

- 大白话；一句一事；单行 ≤60 汉字，最好 ≤30。
- 机制点名：认宗仪典、选路、盖印、沙漏两行、属地墙牌——直接说。
- 不说「系统」「month_echo」——说「沙漏多一行仪典」「属地那块牌」「谁还没选路」。
- 对照物：笔、名册、牌、末页、花生壳圈、印泥。禁精灵耳/鎏金等 anti_trope。
